# 棋盘光栅二维剪切干涉仪：正向模型 + 波前反演（含 Levenberg–Marquardt 直接反演）

一套独立实现的 Python 工程：先建立棋盘光栅二维剪切干涉的**正向光强模型** $W \to I(x,y)$，
再在其上实现两条波前反演路线。

> **参考的文献**：刘志祥，《二维剪切干涉检测技术研究》，电子科技大学博士学位论文，2018，导师：邢廷文。

包含两条路线：

1. **论文给出的路线（必须实现）**：
   $I(x,y)$ —（相移法 / 傅里叶变换法）→ $\Delta W$ —（泽尔尼克多项式）→ $W$
2. **额外的直接反演路线（你的要求）**：
   正向模型 $W \to I(x,y)$ 是非线性的，直接用 **Levenberg–Marquardt（LM）** 非线性最优化从采样光强反推波前系数。

外加**正向模型本身**（衍射级次叠加成像）——它是上面两条反演路线共同的、被验证过的物理基础。

## 1. 正向模型

### 1.1 衍射级次

$45^\circ$ 放置的振幅棋盘光栅（周期 $p$，占空比 $1/2$，无偏置）的第 $(m,n)$ 级振幅有闭式
（用一维方波傅里叶系数组合得到）：

$$A(m,n)=\frac{2}{\pi^{2}\lvert a^{2}-b^{2}\rvert},\qquad (a,b)=\left(\frac{m+n}{2},\ \frac{n-m}{2}\right)$$

（要求 $a,b$ 不同时为偶数。）

`lsi.grating.analytic_orders` 给出解析值，`bitmap_orders` 用真实 bitmap 做二维 FFT 校验。

占空比 $d$ 偏离 $1/2$ 时振幅仍在同一支上连续变化（`harmonic_orders` 的一维方波系数
$S_k=(1-e^{-2i\pi kd})/(i\pi k)$，且有 $A_{mn}=S_mS_n/2$）。当 $m,n$ 同为奇数时：

$$A_{mn}=\frac{2\sin(\pi md)\sin(\pi nd)}{\pi^{2}mn}\,e^{-i\pi(m+n)d},\qquad A_{00}=\frac{1+(2d-1)^{2}}{2}$$

相位因子 $e^{-i\pi(m+n)d}=e^{-2i\pi ad}$ 是光栅原点（沿 $x$ 平移 $d$ 个周期），正是它让 $d=1/2$ 时
精确退化为实值 $-2/(\pi^{2}mn)$（表2-3）；缺了它就会出现 $1/2$ 与偏离 $1/2$ 之间的**符号跳变**
（即 $A(0,1)$ 反号），实测会让 $y$ 向解调常数整体错半个条纹。此外 $m$ 与 $n$ 同偶的级次（在 $d\neq 1/2$ 时才出现）
也会保留；例如 $d=0.6$ 时 $(m,n)=(2,0)$ 的振幅约为一阶的 $10\%$，不能再按零处理。混合奇偶的 $(m,n)$ 会映射到
半整数 detector 坐标，不属于当前 `OrderSet` 的整数 $(a,b)$ 表示范围。

| 级次 | 论文 表2-3 | 本实现（解析/bitmap） |
|---|---|---|
| 0 级 | 25 % | **25 %** / 25 % |
| ±1 级（每个） | 4.11 % | **4.11 %** / 4.11 % |
| 交叉光栅（两方向同时 ±1，每个） | 2.53 % | **2.53 %** |
| 全部级次能量和 | — | **0.5000**（解析精确 $=1/2$，Parseval） |

> 论文 2.1.2 的“0 级和 ±1 级的衍射效率分别为 50%、8.22%”是**矩阵按行（或按列）相加**的口径
> （即把交叉级次也算进 0 级/±1 级）；若剥离交叉项，0 级 25%、每个 ±1 级 4.11%，与 表2-3 完全一致。
> 两种口径本实现都能复现（`diffraction_efficiency()`）。

### 1.2 光强叠加（论文 (2-8)、(2-12)–(2-15)）

对每个级次 $(a,b)$，光束相对 $(0,0)$ 级平移 $(as,\ bs)$（其中 $s$ 为剪切量，等于焦面贝塞尔像间距），
另有相移 $\delta$ 与（傅里叶模式下的）载频 $2\pi f_0(ax+by)$：

$$I(x,y)=\left|\sum_{\mathrm{ord}}A_{\mathrm{ord}}\exp\left(i\left[2\pi W(x+as,\ y+bs)+\delta_{\mathrm{ord}}+2\pi f_0(ax+by)\right]\right)\right|^{2}$$

`ForwardModel` 用该式逐像素求和；`paper_region_intensity()` 实现论文在 4 束/5 束区域内的显式公式。
两者在区域内部**逐点一致到机器精度（相对差 $\sim 10^{-16}$）**，见 `scripts/01`（区域 x1/x2/y1/y2/x5 全部验证）。

相移规律（2.3.1）：光栅沿某方向平移 $p/\sqrt{2}$ 时，其 $\pm1$ 级相位各变化 $\mp2\pi t$，周期为 $1$，与论文 (2-16) 一致
（`ForwardModel.phase_shift_deltas`）；8 步解调所用的 $\delta_k=2\pi k/8$ 由此得到。

**关于“同一 $y$ 方向光束映射到 $\pm1$ 级”**（论文 表2-2 与 图2-6 的两处便利解释）：见 `tests/test_forward_vs_paper.py::test_y_shift_only_moves_y_orders`。
若把某一 $y$ 光束同时算作 $+1$ 与 $-1$ 级，则 4 束光中有两束相位完全相同，此时 (2-12)–(2-15) 会退化为
“只有 2 束光干涉”的形态（论文 式(2-24) 恰好是这种形式）。因此只要被测波前**在该区域是光滑的**，
两种解释给出的干涉图差异只有 $\sim 10^{-3}$ 波量级；而论文 图2-6 按“4 个区域、每区域 4 束光、共 8 束”
的计数（共 $8$ 束，即 4 个光学位置 × 2 个光栅周期方向）与其 (2-12)–(2-15) 的展开式自洽。
本实现的 4 束/5 束区域模型与公式**精确**吻合。

### 1.3 载频（傅里叶模式）

论文 2.4.1 推导的离焦载频为 $f_0=m/(2s)$（其中 $m$ 为泰伯数）。本实现直接施加
$2\pi f_0(ax+by)$ 于各级次——等价于论文结论（论文模型中的二次相位对所有级次相同，会抵消；
$\pm f_0s/2$ 为常量）。这样 $\pm1$ 级干涉项被搬到频谱 $\pm f_0$ 处，可单帧解调。

### 1.4 光瞳与级次支撑区

级次 $(a,b)$ 只在该级次自身的光瞳支撑区内成像，而支撑区是光瞳整体平移 $a\,s$（$s$ 为剪切量）
后的区域。`ForwardModel.pupil` 支持三种形式：

* **不传**（默认）：解析单位圆 $x^2+y^2\le 1$，在**精确的**平移坐标上求值，与剪切是否为
  整数像素无关；
* **可调用** `f(x, y) -> mask`：在同样的平移坐标上求值，因此对任意非圆光阑也是**精确的**
  ——非圆形光阑若确实在意亚像素边缘，应走这条路。返回布尔数组按原样使用，否则以 `> 0.5` 二值化；
* **数组**：必须与 `grid.shape` 同形。级次支撑区由**整像素**索引平移得到（越界补零，不环绕），
  所以仅当剪切是整数像素时才精确，否则光阑边缘有最多半个像素的错位（构造时告警一次）。

  这一错位**不能**靠插值消除：二值掩膜在被采样时就已经丢掉了亚像素边缘位置——0.5 等值线的
  位置被钉在最后个 0 与首个 1 的中点，任何对称插值核给出的都是同一结果（阶数 1/3/5 实测一致）。

`ForwardModel.aperture()` 给出零级支撑区，也即解调阶段该用的区域掩膜；它恒等于
`order_support(0, 0)`。相移路线的 `shear_region_masks` 与傅里叶路线的 `order_support` 都接受
该掩膜，避免正向模型与反演管线对"哪些像素有信号"产生分歧。

`ForwardModel.pupil_definition` 返回**用户传入的定义本身**（可调用 / 布尔数组 / `None`），
反演管线传的是它而不是采样后的掩膜——否则可调用光阑会在相移路线的区域掩膜里被降级成整像素
吸附。实测（正方形光阑、剪切 20.364 px）：可调用光阑的区域掩膜与解析几何**逐像素一致**，
而数组光阑会多出 164 px。

## 2. 论文路线 A：多步相移

`lsi.pipeline.demodulate_phase_shift` → `reconstruct`：

1. **剪切区域判定**（3.1.1）：由最小二乘相移解调得到的调制项 $\lvert A\rvert$（即 $4A_0A_1$ 的区域支撑），
   阈值 + 圆拟合得到 0 级光斑的圆心/半径（`zero_order_center_radius` + `circle_fit`），
   与解析区域 $(x\pm s)^{2}+y^{2}\le 1$ 的交集对比（脚本 02 给出 IoU）。
2. **解调**：取 $\delta_k=2\pi k/N$ 的最小二乘解
   $\psi=\mathrm{atan2}\left(-\sum_k I_k\sin\delta_k,\ \sum_k I_k\cos\delta_k\right)$，单边差分模型下 $\mathrm{d}W=\psi/\pi$。
3. **解包裹**：BFS 路径跟踪（论文 3.1.2 的路径积分）或最小二乘泊松法（带掩膜稀疏解），
   两者都做 **规范固定**（以种子像素的包裹相位为准），否则解包裹结果含 $2\pi$ 整数常量。
4. **差分泽尔尼克最小二乘**（3.2.2）：以 $\Delta Z_j=Z_j(x+s,y)-Z_j(x-s,y)$（双边模型），解
   $\min_c\sum_{\mathrm{pxl}}w\left(\mathrm{d}W-\sum_j c_j\Delta Z_j\right)^{2}$。

**验证**：对 $W=Z_7$（1 波），重建的 12 项系数中除 $Z_7=1.000000$ 外全部 $<10^{-15}$（机器精度）。
论文 表3-2 的结构（仅 $Z_7$ 非零，PV = 1.985、RMS = 0.354）与本实现一致：

| 量 | 论文 | 本实现 |
|---|---|---|
| PV | 1.985 | 1.965（128 网格采样）/ **2.000**（512 网格，解析值） |
| RMS | 0.354 | 0.3536（即 $1/\sqrt{8}$，解析值） |
| 输入 $Z_7=1$ 波 | 3.2.2 节 | 重建值 1.000000000 |

差分泽尔尼克矩阵与论文 表2-5（其中 $Z_4=2\rho^{2}-1$，以及 $Z_5=\rho^{2}\cos2\theta$ 与 $Z_7=(3\rho^{3}-2\rho)\cos\theta$）完全一致：
测试 `test_differential_zernike_matches_table`、`test_difference_models_consistency` 验证 (2-36) 的符号约定与 shear_x $\to Z_4$、shear_y $\to Z_7$ 的对应。
论文 表3-3 中 $Z_{11}=48\rho^{5}-36\rho^{3}+6\rho$ 的径向多项式与文献标准 5 阶球差相差一个因子 3（其 RMS 归一化
与其余项不一致），本实现采用 $Z_{11}=6\rho^{5}-6\rho^{3}+\rho$（Noll 标准）。

**两个必须知道的限制**（都做了数值验证）：

* **半条纹常量与倾斜退化**：0 级与 $\pm1$ 级的振幅积 $A_0A_1=0.5\times 0.2026>0$，而另一对
  （交叉项）为负，因此 $x$ 对与 $y$ 对的干涉项常量相差半个条纹（即 $\pi$）。这个常量与**倾斜项完全共线**：
  若忽略它，则 $x$ 倾斜会吸收 $1/(2s)\approx 6.84$ 波（脚本 02 第 5 节实测 6.8386）。
  本实现按论文的振幅模型**先验地**扣除该常量（`ForwardModel.demodulation_offset`），
  因此倾斜在“振幅已知”的前提下是可测的；若振幅未知，则只能把常量作为自由参数，
  此时倾斜不可辨识（条件数 $\sim 10^{17}$）。
* **大像差失效**：当剪切区内 $4A_0A_1\cos(\cdots)$ 调制项变号（论文 2.3.2 自己指出）时，
  解调相位出现 $\pi$ 跳变，且**不是**单个常量能补偿的。当 $W=6Z_7$ 时，约 $1/4$ 的像素偏离单一常量
  $>1\ \mathrm{rad}$，相移路线只给出 $Z_7=5.67$（真值 6）。此时用 LM（脚本 04）仍然是精确的。

## 3. 论文路线 B：单帧傅里叶变换法

`lsi.ftmode` + `lsi.pipeline.demodulate_fourier`：

* 频谱中找到并精确定位 $\pm f_0$ 瓣（先验窗口 + 抛物线亚像素细化）；
* **两种等效解调器**，相位参考都取在每个像素本身（因此没有全局斜坡）：
  * `lowpass`（默认）：先乘载频 $e^{-2\pi i f_0 x}$ 再在频域做带限低通（Butterworth，半径 $4L$），
  * `local`：高斯窗局部傅里叶变换（窗口 $\sigma=0.06$ 瞳孔单位）；
  * `spectrum`：直接截取 $+f_0$ 频谱瓣——**保留作为参考实现**，其相位参考与前者相差常量，
    不参与定量流程。
* 相移常量：其中 $+f_0$ 瓣是 0 级与 $(+1,0)$ 级的拍频，振幅 $2A_0A_{10}<0$，所以
  $\psi=2\pi[W(x+s,y)-W(x)]+\pi$（**单边**模型）。

关于 (2-42) 的解读（重要）：论文把该瓣的相位写成 $\pi[\mathrm{d}W]$（相对于“双边差分 $W(x+s)-W(x-s)$”）。
由级次平移关系可直接证明该瓣的相位精确等于 $2\pi[W(x+s)-W(x)]$（单边），两者相差
$\frac{s^{2}}{2}W_{xx}+O(s^{4})$——是一个真实的 $O(s^{2})$ **模型误差**，本项目用解析差分验证了该展开
（`test_one_sided_vs_two_sided_model_differ_by_s_squared_curvature`，相对误差 $<10^{-2}$）。
因此傅里叶路线默认按单边模型建模（`difference_model="one_sided"`）。

**精度**（脚本 03，在 $256^{2}$ 网格上取 $W=0.6Z_7$）：主项 $Z_7$ 恢复误差 $\sim 10^{-4}$；低阶项存在 $\sim 0.04$ 波量级的
滤波偏置串扰（解调窗在区域边缘把暗区混入所致，用 $\sigma$ 更小/带宽更窄可改善）。区域像素还需要按
滤波核宽度做**内缩**（`erode_px`，默认 4 px），否则边缘偏置会显著污染 $Z_4/Z_5$。

## 4. 额外路线：Levenberg–Marquardt 直接反演（你的要求）

`lsi.lm`：把正向模型直接当作非线性最小二乘问题

$$c^{\ast}=\arg\min_c\sum_k\sum_i\left[I_k(i)-\left|\sum_m A_m\exp\left(i\left[2\pi W_c(x_i+sa_m,\ y_i+sb_m)+\delta_{km}+2\pi f_0(a_mx_i+b_my_i)\right]\right)\right|^{2}\right]^{2}$$

* 残差向量 $r(c)$：测量帧与模型帧逐像素之差（可加 scale/background 两个线性未知量，
  用变量投影法消去，或在 LM 中一并优化）；
* **解析雅可比**：其中 $\partial I/\partial c_j$ 通过 $\partial E/\partial W=i\cdot 2\pi\,\partial W/\partial c_j\cdot E$ 逐级次链式展开（`ForwardModel.model_and_jacobian`），
  与有限差分对照误差 $<10^{-4}$（`test_analytic_jacobian_matches_finite_differences`）；
* **Marquardt 阻尼 + 自适应 $\lambda$**（gain ratio 判据）；阻尼步通过增广最小二乘
  $[J;\sqrt{\lambda D}]\,\Delta\approx[-r;0]$ 求解，不显式形成会把条件数平方的 $J^T J$；
  目标函数是最小二乘，没有鲁棒核；
* **变量投影**：`fit_scale_background=True` 时用变量投影法消去 scale/background，缩减雅可比按
  Golub–Pereyra 对投影算子逐列求导（`lsi.lm.reduced_scale_background`），与缩减残差的有限差分
 对照误差 $<10^{-8}$；返回的 `cond` 是 **Jacobian 自身**在**解处**的 2-范数条件数 `cond(J)`
 （与 `reconstruct` 报告 `cond(A_w)` 的约定一致；改报 `cond(J^T J)` 会把这个数字平方，
 使正常的 $10^6$ 看起来像完全不可辨识）；
* 采样：`samples=None` 取整幅网格，否则用 `rng.choice(..., replace=False)` 不放回随机抽取
  （不是等距网格，也不保证区域边界无混叠）。

**结果**（脚本 04 的 $96^{2}$ 网格）：

| 场景 | 结果 |
|---|---|
| 8+8 帧相移数据（6 个未知系数） | 6 次迭代、0.33 s，系数误差 **$1.9\times10^{-13}$** |
| **单帧**载频干涉图（12 个未知系数） | 误差 **$2.2\times10^{-16}$**（无需相移、无需解调、无需解包裹） |
| 未知对比度（scale $=2.3$、背景 $=0.17$） | scale、background 与系数全部精确恢复 |
| SNR 60→20 dB | 单调退化，30 dB 时误差 $\sim 10^{-3}$ 波 |
| $W=6Z_7$（相移路线失效） | 粗扫描 + LM 精修 → **6.00000**（相移路线 5.674，原因见 §4.1） |

结论：LM 路线比论文路线少两个中间环节（不需要相移量标定、不需要解包裹），
在**大像差**和**振幅/背景未知**的场合明显更强；代价是需要一个好的初值（本项目用对主导项
做粗扫描的 `multistart_fit`；5 波以内的像差用零初值即可收敛）。

### 4.1 相移/傅里叶解调路线的适用上限（实测：不是解包裹的锅）

把 $W=A\cdot Z_7$ 的振幅 $A$ 从 0.25 扫到 6 波，用论文的剪切量（取 $s=0.0731$，8 步相移、
$96^{2}$ 网格），与解析差分逐点比较（比较用 `demodulate_phase_shift` 给出的**重叠区掩模**，
即 pupil ∩ 平移后 pupil；用整个光瞳比较会把掩模外的无定义相位当成误差）：

| $A$（波） | 0.25 … 3.0 | 3.25 | 3.5 | 4.0 | 6.0 |
|---|---|---|---|---|---|
| 解调调制 $\min\lvert Z\rvert$ | 0.276 → 0.0130 | **$8\times10^{-6}$** | $1.1\times10^{-3}$ | $4.2\times10^{-4}$ | $7.7\times10^{-4}$ |
| 相位残数（涡旋）| 0 | **4** | 4 | 4 | 4 |
| 差分 $\mathrm{d}W$ 最大误差 | **0.00000** | — | 1.000 | 2.000 | 2.000 |

即：**当 $A\le 3$ 波时整条线性路线逐点精确（即 $<10^{-9}$，实测 0.00000），而 $A\approx 3.1$ 波处调制穿过零点**，此后解包裹开始整波地丢数：3.5 波时丢 1 波，而 $\ge 4$ 波时丢 2 波。因此 6 波 $Z_7$ 的系数被拉低到 **5.6–5.8**（丢波发生在局部区域、再由 Zernike 拟合平均，故具体数值随网格/掩模/采样而变，在 $128^{2}$ 网格上为 5.64、在 $96^{2}$ 上为 5.67，`indices=[7]` 单点拟合为 5.75），而 LM 路线给 6.00000。

三个对照把机制钉死，全部写成 `tests/test_demodulation_limit.py`（7 个用例）：

1. **不是解包裹算法的锅。** 把*真值*包相位（6 波 $Z_7$，差分跨 12.5 波）交给同一个 `unwrap_seed_growth`、同一个掩模：逐点误差 $<10^{-9}$，且掩模内相邻像素步长处处 $<\pi$、残数恒为 0——数据本身完全可解包裹。
2. **是正交剪切的串扰。** 一阶（时间）谐波解调同时收进 $(1,0)\cdot(0,0)^{\ast}$ 与 $(0,1)\cdot(0,0)^{\ast}$ 两项，于是 $y$ 向剪切的分量漏进 $x$ 向解调。只保留 $(0,0)$ 与 $(\pm1,0)$ 三束（去掉 $(0,\pm1)$）后，同一振幅下 $\min\lvert Z\rvert$ 保持 0.19–0.28、残数恒为 0、**$A=3.25$ 与 4.0 波仍精确到 $<10^{-9}$**。
3. **零点是失效的直接原因。** 被漏进来的分量把 $\min\lvert Z\rvert$ 压到 0（3.0 波时还有 0.0130，3.25 波时 $8\times10^{-6}$），零点处解调相位的虚实部同时变号 → 出现 4 个涡旋残数 → 解包裹只能整波地错。

实践含义：论文 2.3.2 说解调法要求“小像差”并非保守。对本文装置的剪切比，**单一 $Z_7$ 的可用上限约 3 波**；高像差、或振幅/背景未知时，用 §4 的 LM 路线（不需要解包裹，因而完全不受零点影响）。

## 5. 误差因素（论文第四章）复现

`scripts/05`：

| 误差源 | 结果 |
|---|---|
| 占空比 0.40→0.60 | 级次振幅按闭式连续变化：其中 $A(0,0)$ 项 0.5000→0.5200，而 $\lvert A(1,0)\rvert$ 项 0.2026→0.1833，四个 $\pm1$ 级合计效率 16.43 %→13.44 %（表4-3 的“效率下降”趋势一致）；**波前形状完全不变**（即 $\le 1.6\times10^{-15}$ 波，占空比只改振幅不改相位），但解调常数推移 $\arg A(1,0)=\pi-2\pi(d-\frac{1}{2})$（其中 $A(0,1)$ 不动），若仍按 50 % 光栅先验解调，误差全部落进不可测的倾斜项（当 $\varepsilon=\pm0.05$ 时 0.68 / 13.0 波，符号取决于 $2\pi$ 绕回）；先验随实际振幅更新则倾斜也精确 |
| 高级次串扰（即 $\pm2/\pm1$ 交叉级次，2.53 %） | 保留 $\lvert a\rvert,\lvert b\rvert\le 3$ 的全部奇次谐波后，即使 50 % 占空比也有 $4.2\times10^{-2}$ 波偏差（一阶谐波解调不能区分 $(1,0)$ 与 $(1,\pm2)$ 的拍频）——这是“只用 4/5 束主级次”假设的代价，误差随占空比变化在 $1.5\times10^{-2}\sim 4.2\times10^{-2}$ 波之间 |
| 相移步长标定误差 $0.5^\circ \to 5^\circ$ | 一阶敏感：如 $1^\circ$ 误差 → $1.6\times10^{-3}$ 波（4 步）/ $6.8\times10^{-4}$ 波（8 步）；随机抖动（如 $\pm0.5^\circ \to \pm5^\circ$）为 $1.3\times10^{-3}$→ $1.2\times10^{-2}$ 波（4 步）/ $3.0\times10^{-3}$→ $3.0\times10^{-2}$ 波（8 步） |
| 剪切（光栅周期）相对误差 | 系数整体成比例 $(1+\varepsilon)$：其中 $\varepsilon=1\,\%$ → 最大系数误差 $3.1\times10^{-3}$ 波、系数范数比 1.010000，即 $\mathrm{d}W\propto s$，属“标尺误差”（唯一可乘的误差通道） |
| 噪声（SNR 30 dB） | 4/8/12 步误差 $1.9\times10^{-3}$ / $1.5\times10^{-3}$ / $1.2\times10^{-3}$ 波（随帧数下降，符合匹配滤波预期） |

论文 4.2.2 的定性结论（占空比误差主要影响条纹对比度/像面分布，而相位主要受光栅**周期**与
高级次串扰影响）在本模型中成立：占空比误差不改变任何一项波前形状系数（剩下的只有振幅变化
和与倾斜退化的“半条纹常数”），而周期误差是纯粹的标尺误差。

## 6. 与论文数值的一致性 / 不一致之处（如实记录）

**一致**：表2-3 衍射效率；式(2-12)–(2-15)（逐点机器精度）；表2-5 泽尔尼克编号与符号约定；

**需要指出**：

1. 表2-3 的 PV $=1.985$ 与其自身基函数不完全自洽（同一基函数在 512 网格上是 PV $=2$，在 128 网格上
   是 1.965）——差异属于离散采样，不是模型错误。
2. 式(2-42) 的“π·双边差分”解读与级次平移关系给出的“2π·单边差分”相差 $O(s^{2})$，本项目按后者建模。
3. 论文 表2-2/图2-6 中“同一 $y$ 方向光束映射到 $\pm1$ 级”的说明，与其式(2-12)–(2-15) 的展开在“4 束光”
   计数下不完全自洽（详见 §1.2）；对光滑波前两种解释的差异在 $10^{-3}$ 波量级。
4. 论文 2.1.2 的“50 % / 8.22 %”是矩阵行列求和口径，与 表2-3 的 25 % / 4.11 % 并不矛盾。
5. 论文 表3-3 的 $Z_{11}$ 径向多项式与标准 Noll 5 阶球差差一个因子 3（其余项皆一致）。
6. 论文 4.2.2 只说“占空比误差改变衍射效率”，没有给出偏离 $1/2$ 时各级次的**相位**；本项目按
   一维方波系数补出了完整闭式（§1.1），可证明它只改振幅与那个与倾斜退化的半条纹常数。

另：论文正文 4.3.1 声称用干涉仪实测了 PCX 透镜，但全篇没有实测条纹图、探测器和相移标定误差的
定量描述，文中的“实测”结果实际上仍是仿真数据——因此本项目的验证对象是**仿真数据上的算法与公式**，
而不是论文的实物测量结论。
