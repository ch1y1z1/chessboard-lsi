选区会改变恢复精度，收益随波前而变。交集腐蚀改善了多数已测真值；中心不确定的关键情形仍待验证。

## A 这次比较了什么
```kv cols=2

```

频域窗口决定提取哪些边带信息。空间交集掩膜决定用哪些相位像素拟合。

```callout info 评价区域始终相同
全部结果在完整的 52,428 像素光瞳上计算原始 RMS，35 项系数全部自由拟合。腐蚀只改变拟合所用像素。
```

## B 腐蚀后，FT 与 LM 仍有差距
```chart bar horizontal
方法 | 单源 | 64 源
默认 FT | 4.433 | 3.802
FT · er12 | 3.325 | 2.521
run-08 LM | 0.496 | 0.507
```

图示为 40 dB 五种子的均值，单位 10⁻⁴ waves，越低越好。样本 SD 按图中顺序为：单源 0.013、0.016、0.087；64 源 0.016、0.018、0.093。

er12 后，FT/LM 均值比仍为 **6.70 / 4.97**。现有单项调整未消除差距，也未识别各因素的因果贡献。LM 复用同一观测的 run-08 结果。

## D 腐蚀改变拟合边界，收益有适用范围
![左：er12 删除的交集边界像素。右：仍在同一完整光瞳上评价的主真值 clean RMS。](/home/chiyizi/.lody/chats/f473f848-c5f2-400d-89a7-db78912d1092/research/output/figures/05_mask_erosion.png)

er12 保留 **92.71%** 的交集拟合像素。主真值 clean RMS 下降 **25.1% / 33.9%**。

两种源数均有 **10/13** 个随机真值改善；最差真值变差 **4.3% / 5.2%**。腐蚀涉及内、外及移位交集边界，又与补零平滑耦合，尚不能把收益直接归因于衍射泄漏或 Gibbs 效应。

## E 中心问题还没有测完整
共窗重标定下，x 中心偏移 ±3 bin，约为载波的 ±1.06%。主真值 RMS 最大/最小比为 **1.039 / 1.055**；极差约为基线噪声 SD 的 **13.2 / 12.4 倍**。

| 检查项 | 当前限制 |
| --- | --- |
| y 中心偏移 | 窗口与定位的坐标应用不一致 |
| 名义亚像素组 | 实际退化为整数窗口 |
| 自动中心模式 | 窗口固定，未启用真实分数移频 |
| 测量—标定失配 | 尚无对应结果 |

当前数据不足以给出一般性的中心定位容差。

## F 下一步先补哪些证据
- 修正中心坐标、分数移频及幅度筛选后的伪逆，再检验测量—标定中心失配与分数剪切。
- 保留 er12、等面积圆窗、σ=20 为候选；补做等有效带宽窗形及边界平滑对照。
- 参数选定后，以新的独立真值检验。现有 13 个真值已参与比较；它们没有对应的 LM 恢复结果。

本页整理已有结果，未启动新数值实验。结论限于当前标量 Fresnel 系统、噪声模型和已测波前；根因尚未确定。
