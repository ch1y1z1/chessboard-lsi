# 重构与数据验收

基线是 PR16 最终提交 `8628f3c`。本次只做四源小场景核对，没有在本机重跑原采样研究。

## 当前结构

- `lsi/config.py` 分开保存 `SystemConfig`、`Scene`、`FitConfig`。系统对象没有真值系数；反演只接收物理模型、显式未知模式和观测。
- `forward.py`、`basis.py` 保留参考离散算子、环形基编号和归一化；`fourier.py`、`direct.py` 保留解算数学。
- `run.py` 只编排比较、选区和倾角实验；保存逻辑在 `io.py`；CLI 只负责选择工作流、JSON 配置和输出位置。
- 参考脚本适配与绘图移至 `tools/`。绘图只读已经保存的系数和观测，不执行传播或拟合。
- 移除理想五光束模型、手写旧 LM、旧相移解算、重复入口、一次性补算/合并脚本及过时交接文档。源代码仍可从 Git 历史定位，不保留兼容入口。

## 验收证据

`uv run pytest -q`：8 项通过，覆盖以下四类检查。

1. 独立参考黄金数组：源面、物镜面、相机复场、全部四源叠加强度，以及两个傅里叶边带的包裹相位。
2. 可分离算子与逐段 CZT：含倾角和位移的小场景；同时核对解析导数、有限差分和抽样像素导数。
3. 两种解算方法：独立标定的小信号混合波前、增益/背景恢复、完整变号不能算正确恢复，以及 PR16 冻结结果。
4. 工作流数据：同一观测供给两种方法，配置/单位/轨迹/源码快照完整，窗口冻结和角度 fixed/auto 各自标定协议一致。

另外，直接调用用户的 BUV0725 脚本做四源核对：源场相对误差约 `1.75e-11`，相机场约 `1.42e-11`，全四源叠加强度约 `3.26e-12`。核对过程未改动参考的数值运算。

`tests/data/refactor_baseline.json` 是重构前从 `8628f3c` 独立导出的四源算例，包含一张干净图与三组 40 dB Gaussian 噪声样本的两种解算结果。新代码对系数与 RMSE 使用 `rtol=1e-9`、`atol=1e-11` 的回归容差；仅含噪直接拟合的绝对容差为 `1e-8 waves`。Linux CI 与 macOS 的含噪 TRF 有限精度停止点出现约 `1e-9 waves` 差异，因此单独设置此容差，未修改冻结数据或前向模型。此粗采样场景只检查数值一致性，其傅里叶误差不能当成原采样精度。

验收摘要及未变历史文件的 SHA256 见 [refactor-validation.json](refactor-validation.json)。已有 PR16 JSON 数字摘要和独立黄金数组与基线逐字节一致；原始大数组继续留在远端。原采样 RMSE、噪声统计和倾角曲线没有在这次重构中重新验证。

## 运行变化

唯一生产入口为 `python -m lsi compare|regions|angles`。参数编辑示例在 `configs/`，不再兼容旧模块名、旧命令或旧 JSON 的真值混入系统配置方式。可通过 `compare` 的 `sweep.noise_seeds` 重复噪声实验，通过 `fit.starts` 与 `screen_initials` 检查初值，通过修改 `scene` 检查不同波前。

独立选窗策略和中断批次补算不再藏在主工作流中；`regions` 只按明确给定的窗宽、中心、形状和掩膜做有限扫描，不会偷偷根据测试真值选择生产参数。历史研究的选窗策略结果保留在原报告中。

`source_snapshot/` 保存运行时的新代码和锁文件，`manifest.json` 同时记录系统、真值、拟合设置、噪声种子、扫描参数、耗时和内存。算法停止、结果保存成功和波前恢复成功仍分别记录。
