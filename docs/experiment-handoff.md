每次只运行一个研究任务，保留进程锁和中断结果，不覆盖已有输出。

## 起点与已有结果

先阅读 `docs/experiment-status.md`、`docs/implementation-report.md` 和 `docs/research-plan.md`。
当前代码已通过 32 项小场景测试。
`docs/results/verified-summary.json` 保存主对比与核对结果。

- 原采样：相机 N=1200，光栅 N=2400，64 源逐个传播后叠加强度。
- 原脚本全源强度核对相对 L2 误差：5.0356e-12。
- 已完成零角度、四模式、0.1 waves RMS、无噪声主对比。
- 标定傅里叶 RMSE：9.3268e-4 waves；直接法：4.2401e-18 waves。
- 后者仅是一次同模型无噪声恢复，不能当作实测精度或一般成功率。
- 原采样选区只有直接基线、名义窗 20、半宽 8 和 12，共 4 行。
- 原采样角度只有零角度的两种方法，共 2 行。
- 粗采样扫描仅作诊断；傅里叶粗采样误差约 0.1018 waves，不能用于精度结论。

## 参考与数据

BUV0725 的传播模型和 Retrieval0806 的解算约定优先于旧仓库简化模型。
会话附件提供两份参考的 Python/JSON 文件，以及现有基准数据和局部扫描记录。
Git 仓库保留小场景原脚本基准；完整运行数据未纳入 Git。
附件中的路径清单和 SHA256 用于核对接收完整性。

`Square` 是 25% 开口面积的周期方孔阵列。
不能换成旧五束理想棋盘模型，也不能用代表源代替全部 64 源。
`reference` 与 `retrieval` 的物面轴移/error_mode 不同，分别保留。
模式下标采用参考零基顺序，默认未知模式为 `7,25,11,15`。
原版傅里叶系数是 a.u.；标定版额外使用独立标定数据，须分列报告。
参考倾斜仅为输入场相位坡度近似，不是严格旋转平面传播。
物面单像素点源倾斜是零效应对照；旧 NPY 生成参数未明确，不猜测其角度。

## 后续顺序

1. 检查远端内存及容器配额，安装锁定依赖，运行小场景测试。
2. 用附件核对现有原采样基准；优先复用独立标定数据，避免无意义重算。
3. 完成原采样选窗与空间掩膜研究。先小范围逐项扫描，再扩大敏感区间。
4. 完成原采样部件角度对照。先相机/光栅的单轴小角度，再扩展方向和幅度。
5. 按计划补充多种混合波前、噪声重复和初始化稳定性，报告局部极值与失败。
6. 更新简报和完整研究报告，提交后续代码/结果摘要 PR，勿自动合并本 PR。

选窗主实验冻结名义标定；逐窗重标定作为独立诊断。
验证集选窗与测试真值最优窗分列，不用测试真值选生产窗口。
角度研究分开报告已知几何和忽略几何，固定与自动中心使用相应几何的同一标定。
每张图只有一份物理生成配置，两种方法使用相同观测和评价光瞳。
保存完整配置、代码版本、独立标定/验证样本、收敛轨迹、失败及资源消耗。

参考命令见 README。远端资源足够时可显式使用 `--allow-large-run`。
现有 CLI 不支持自动续跑；使用新输出目录，并单独汇总已有部分结果。
默认 worker 和 batch 均为 1，不并行启动多组实验。
