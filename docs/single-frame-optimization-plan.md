# 单帧无调制光强直接估计 Zernike 系数：评估与实验方案

日期：2026-09-28。本文基于当前仓库源码、全部回归测试及现有演示的实际运行；未对参考博士论文逐页核验。文中的实验网格与预算为建议值，尚未执行多优化器比较。

## 1. 结论与问题定义

建议开展。项目已有完整的可微前向模型及解析雅可比，新增优化器无需重新实现物理模型。准确的研究问题是：**在固定的单帧、无相移、无空间载频采集条件下，不同非线性优化算法直接拟合原始光强时，在恢复精度、恢复成功率、计算成本和噪声鲁棒性上如何表现？**

LM 是非线性最小二乘的一个求解器。梯度下降、Momentum、Adam、BFGS、Gauss–Newton（GN）、LM 和信赖域法可以求解同一个光强拟合问题；“非线性最优化”是这些方法所属的共同路线。

这里的“无调制”按现有代码定义：保留棋盘光栅及剪切干涉，不附加相移序列，不加入空间载频，不使用已知相位偏置。输入仅为一帧二维探测器光强。优化变量直接是 Zernike 系数，不经过相位解调或解包裹。

需要限定恢复目标：默认实振幅模型无法仅凭该图像确定整体正负号，piston 不可观测，倾斜还存在周期等价。应研究指定物理参数范围内的等价类恢复，不能承诺任意波前的唯一、有符号恢复。

## 2. 项目现状

| 文件 | 已有能力 | 对新实验的作用 |
| --- | --- | --- |
| `lsi/model.py` | 采样网格、系统参数、光栅级次、Fringe/Wyant Zernike 基、相干叠加光强、基矩阵缓存 | 所有算法共用的前向模型 |

| `lsi/invert.py` | 相移/傅里叶解调、Poisson 解包裹、差分 Zernike 线性最小二乘 | 项目背景；其采集条件不属于本次主比较 |
| `experiment.py` | 三条演示路线；第 5 节已有单帧无调制多初值 LM | 最小复现基准 |
| `test_lsi.py` | 模型与显式公式对照、基函数、解调、LM 雅可比及恢复测试 | 已有正确性基础 |

当前默认模型为 0 级及四个一级的五光束模型，各级振幅为实数。单位圆光瞳、均匀振幅、理想几何、点采样光强；波前以 waves 为单位，Zernike 基未按单位 RMS 归一化，支持至 Z36。采集数据均由模拟生成，仓库未见实测相机原始数据及相机标定流程。

已有 LM 实现值得保留：阻尼步用增广最小二乘求解，避免直接求逆法方程。现阶段限制是最大迭代数与容差为模块常量，缺少逐步轨迹、调用计数、计时及详细退出原因；`converged=True` 仅说明满足停止条件。`_frame_and_jacobian` 每次同时计算光强和雅可比，后续需要支持仅计算光强，减少线搜索及拒绝步的无用计算。

### 本次实际验证

- `uv run pytest -q`：11 项通过。
- `uv run python experiment.py`：完整运行成功，结果在 `output/lm_unmodulated.csv`。
- 现有无调制实验：128×128，全图拟合 Z2…Z13；一个真值，10 个随机方向分别缩放到 0.03、0.1、0.3 waves RMS；方向跨幅值组复用。

| 初值波前 RMS / waves | 恢复到 ±真值 | 说明 |
| --- | --- | --- |
| 0 | 0/1 | 第一次迭代即停止，光强 RMS 残差约 0.06864 |
| 0.03 | 1/10 | 成功的是方向 8 |
| 0.10 | 1/10 | 成功的是方向 8 |
| 0.30 | 1/10 | 成功的是方向 8 |

成功阈值为允许整体变号后的最大系数误差小于 1e-6 waves。30 个非零初值中成功 3 次，但这不是 30 个独立真值上的统计成功率；三个成功初值还共享同一个方向。其余运行同样报告 `converged=True`，光强 RMS 残差约 0.008～0.016，说明停止标志不能作为恢复成功指标。

额外在 64×64 网格、相同真值上验证：`I(c)-I(-c)` 最大绝对值为 0，`J(0)` 为 0；真值处 12 列雅可比满列秩，条件数约 40.1。该结果支持此真值邻域内的局部辨识，不能证明全局唯一性或其他波前均可恢复。

## 3. 可辨识性与优化难点

### 3.1 整体正负号不可区分

无附加相位且各级振幅为实数时：

\[
E(-c)=\overline{E(c)},\qquad I(-c)=I(c).
\]

因此所有拟合系数整体取反，得到同一帧光强。比较必须允许一个共同符号，不能逐项任意翻转。若产品最终要求绝对符号，需要额外物理先验或观测；换优化器无法补足缺失信息。一般复振幅或额外已知相位情形需重新分析，不能直接沿用此结论。

### 3.2 零初值对常用局部方法无效

由于强度关于 c 为偶函数，当前模型中 `J(0)=0`，平方残差的梯度也为零，GN 近似 Hessian `JᵀJ` 同样为零。普通 GD、Momentum/Adam（零初始动量）、GN 和 LM 无法凭该处的一阶信息主动离开。

这不意味着零点一定是局部最小值，精确 Hessian 可能含有 GN 忽略的残差二阶项。第一版应统一采用非零初值；零初值作为独立的退化诊断。近零波前也值得重点研究：强度变化从二阶起步，固定探测噪声下，小像差可能更难稳定估计。

### 3.3 不止正负号：倾斜的周期等价

项目中 Z2=x、Z3=y，默认级次坐标 a、b 为整数。增加波前

\[
\Delta W(x,y)=(k x+l y)/s,\quad k,l\in\mathbb Z
\]

时，各级额外因子是共同相位乘 `exp(i 2π(ka+lb))=1`，光强不变。因此 Z2/Z3 各有 `1/s` 的周期等价。当前默认 s≈0.07311，周期约 13.6773 waves；数值验证 c2 增加一个周期后最大光强差约 1e-14。

主实验的真值和初值幅度远小于该周期，但无约束求解器仍可能跑出范围。评估时保留原始系数，另报告倾斜按该周期映射到预先约定基本区间后的误差；标注周期别名，不将其直接归为拟合失败。不为个别算法单独加界限；有界优化另做所有参赛方法都遵循同一范围的实验。

### 3.4 局部解、弱观测方向与模型失配

相位进入指数函数，目标一般非凸。当前实验已观察到多个具有非零残差的停止点。不同模态、剪切量、幅度和图像区域会改变雅可比条件性；只比较一次随机初值没有代表性。

先检查真值和估计值处雅可比的奇异值，再结合多初值解聚类分析歧义。满列秩只支持局部结论；不把“只观察到 ± 两个解”写成唯一性证明。高阶截断、振幅偏差、像素积分及标定误差也可能使残差无法降到零。

## 4. 统一反问题

所有方法共享：

\[
W(x,y;c)=\sum_{j\in\mathcal J}c_jZ_j(x,y),
\]

\[
E_p(c)=\sum_{a,b} A_{ab}P(x_p+as,y_p+bs)
\exp\!\left[i2\pi\sum_jc_jZ_j(x_p+as,y_p+bs)\right],
\qquad \hat I_p(c)=|E_p(c)|^2,
\]

\[
\min_c F(c)=\frac{1}{2M}\sum_{p\in\Omega}
\left(\hat I_p(c)-I_p^{\mathrm{obs}}\right)^2.
\]

第一阶段不加正则、不拟合 gain/background、不逐图做 min-max 归一化，排除 Z1（piston）。每个样本只提供单帧观测。像素数归一化使不同分辨率下的目标尺度一致；噪声加权作为另一个共享目标单独比较。

解析梯度与近似二阶信息统一来自：

\[
J_{pj}=2\operatorname{Re}\left[\overline E_p\,
i2\pi\sum_{a,b}A_{ab}P_{ab,p}Z_{j,ab,p}e^{i\phi_{ab,p}}\right],
\quad \nabla F=J^Tr/M,\quad H_{GN}=J^TJ/M.
\]

当前 LM 使用 `||r||²`；引入均值目标后必须一致调整 residual、Jacobian、停止尺度和日志，避免混用 sum 与 mean。GN/LM 可传入 `r/√M` 和 `J/√M`，并明确库内部的 1/2 系数。

### 参数尺度与像素选择

- 采用共同的波前 RMS 参数缩放：在固定光瞳网格计算 `d_j=std(Z_j)`，令 `q_j=d_j c_j`，优化 q，最终转回原始 Fringe 系数。初值和真值的总 RMS 用实际叠加波前计算，不简单以系数欧氏范数代替。
- 主比较均使用同一 q 坐标；再单独消融原始 c 坐标，避免某一方法独享标准化。LM 自带阻尼尺度仍属于方法自身，需记录。
- 初版使用全部 128×128 像素，与现有实验一致，保留边缘重叠区。不使用随真值或当前估计变化的 mask。
- 在已知均匀振幅模型下，零/单光束区对相位无信息；可预先按几何去除以加速，但所有方法必须共用 mask。全图残差与有信息区域残差分别记录，防止暗区稀释误差。
- 单帧不等于一个标量观测；图像中有大量像素约束，但像素多于系数并不保证唯一性。

## 5. 比较算法

| 方法 | 第一版配置 | 主要回答的问题 |
| --- | --- | --- |
| GD | 全像素梯度，Armijo 回溯线搜索 | 基本一阶基线 |
| Momentum | 全像素梯度，验证集选择学习率与动量 | 动量是否改善速度及成功率 |
| Adam | 全像素梯度，无 weight decay，验证集选学习率/衰减 | 自适应步长是否有实际优势 |
| BFGS | 解析梯度、线搜索 | 低维拟牛顿法的表现 |
| GN | QR/SVD 求 `min ||Jδ+r||`，配回溯线搜索 | 最小二乘结构带来的收益 |
| LM | 当前实现，开放阻尼/容差/预算配置 | 阻尼对局部解和病态性的作用 |
| TRF | SciPy `least_squares(method='trf')`、解析雅可比 | 信赖域步长控制的作用 |

七种足以覆盖主要类别。Momentum 与 Adam 的学习率可用 1e-4、1e-3、1e-2、1e-1 的对数网格作为先导搜索起点；这不是已验证的最优范围，必要时在验证集上扩展。Momentum 动量可先试 0.9、0.99，Adam 可从标准 beta 配置开始。各法分配相同的调参计算预算并保存完整配置。

第一版均使用全像素梯度；框架里 `SGD` 不带动量且全批量时就是普通 GD。像素小批量 SGD 另作扩展，固定采样策略并把一次更新所用像素数计入计算量。Adam 的原论文描述其基于一阶梯度及矩估计的更新，但不保证本问题上优于最小二乘方法：[Adam 原论文](https://arxiv.org/abs/1412.6980)。

SciPy 的 `least_squares` 提供 LM、TRF 和 dogbox；TRF 不是纯 GN，dogbox 是另一类信赖域实现；其中 LM 不支持边界。因此纯 GN 需要单独实现，第一版主比较统一无约束，显式指定参数缩放，避免库默认值混入比较：[SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。

扩展顺序建议：RMSProp/Nesterov、L-BFGS（高维时）、纯单位步长 GN（诊断）、Adam→LM/BFGS→LM（组合方案）。组合方案必须计入两个阶段的总成本，与同预算多初值 LM 比较。精确 Hessian 信赖域可用于研究零点附近的负曲率，暂不作为第一版工程重点。

## 6. 数据与实验阶段

### A. 复现与正确性检查

沿用现有真值、128×128、Z2…Z13、31 个初值，七种算法共享完全相同的观测和初值。单独验证无调制解析雅可比、`I(c)=I(-c)`、`J(0)=0`、piston 不可观测及倾斜周期。

目的：验证接入正确，观察各算法走向哪些解，不以单一真值给出总体排名。保留目前 LM 输出作为历史基准。

### B. 无噪声主比较

| 因素 | 建议取值 |
| --- | --- |
| 模态数 | 首先 Z2…Z13；扩展 Z2…Z6、Z2…Z21、Z2…Z36 |
| 真值类别 | 单模态扫描；稀疏混合；稠密混合；另设高阶衰减谱 |
| 真值波前 RMS | 0.01、0.03、0.1、0.3、1.0 waves |
| 初值 | 10 个随机方向 × 0.03、0.1、0.3 waves RMS |
| 网格 | 主实验 128×128；64×64 与 256×256 作分辨率扩展 |
| 系统参数 | 首先固定现有 λ、NA、p；随后单因素改变剪切量 |

真值系数先在共同的 RMS 缩放坐标中生成方向，再按实际波前标准差缩放。稀疏度、系数分布与种子必须保存。先固定 12 个未知量，每个真值幅度生成 20 个独立混合波前，共 100 个真值；每个真值 30 个相同初值，七法共 21,000 次局部运行。单模态诊断另外记账。

先导阶段可以只用现有真值加 10 个随机波前，核定每次运行成本后启动正式集合。模式数、分辨率、剪切量暂做单因素扩展，避免立即把所有维度全组合。验证集与测试集使用独立的波前方向和随机种子。

输出两套结果：每个共享初值上的局部求解表现；每个真值在固定总预算下多初值搜索的最终表现。二者不能混成一个成功率。

### C. 噪声鲁棒性

先使用与 `experiment.py` 一致的高斯加性噪声定义：`SNR=20 log10(max(I_clean)/sigma)`，取无噪声、60、40、30、20 dB。固定噪声实现供各法共用；每个条件建议 5 个独立噪声种子。先选代表性的 20 个真值，评估预算后再扩展。

报告该 SNR 是峰值光强口径，且不可直接衡量小像差变化的可见性。保留波前幅度与噪声强度的二维分析。高斯主实验不将负观测值裁剪到零，以免改变噪声模型。

随后增加以电子计数定义的 Poisson 光子噪声及读出噪声。先固定同一平方损失比较优化器，再将共同目标改成噪声匹配的似然/加权残差进行单独比较；若某算法同时更换损失，须把目标变化作为独立因素说明。不能由同源仿真直接推断实测性能。

### D. 模型失配及实测准备

分项加入：生成端比拟合端更多 Zernike 项、振幅不均匀、剪切量偏差、光瞳中心偏差、像素面积积分及读出背景。更多衍射级只在实际光路允许通过时纳入，并检查视场是否覆盖。

独立高分辨率生成再进行像素积分，有助于避免生成和反演完全同模型带来的过度乐观。gain/background 的联合估计放在已知参数基准之后；若引入，所有算法应面对相同增广参数和目标，同时检查它们与波前的耦合。

实测数据需要明确：探测器线性标定、暗场/增益、坐标与剪切标定、饱和/坏点 mask、实际级次与振幅。允许使用事先固定的仪器标定；每次待测波前的反演输入仍是一帧。额外多帧或参考仪器只可用于独立评价，不进入待比较算法。

## 7. 初值、预算与调参公平性

1. 保存统一的观测、像素 mask、系数顺序、初值池、噪声种子；每个算法逐项配对运行。拟合过程中不能使用真值选择初值或停止。
2. 初值保持与真值独立，固定 0.03/0.1/0.3 waves RMS；不根据每张图真实 RMS 缩放初值。不要将 ±c0 当成两次独立探索，它们在对称目标和相同算法下通常对应镜像轨迹。
3. 所有方法使用同一 float64、CPU 和线程配置；共享同一解析模型。第一版允许 GD 使用现有 J 计算梯度，随后评估不显式存储 J 的梯度实现；不同实现的内存和时间成本必须说明。
4. 首次比较可统一设每次最多 500 次光强、500 次雅可比计算为保护上限，同时记录全部调用；这不代表相同计算量。线搜索、拒绝步也计数，缓存命中不重复算实际计算。
5. 正式报告以实测时间—精度/成功率曲线为主，附前向、梯度、雅可比次数及迭代数。预算刻度根据独立先导试验确定后锁定，可先尝试每次 1/5/20 秒。无法中断的最后一次计算记录实际超时。
6. 多初值按“每个真值的总时间”匹配，而不仅是每次迭代上限；也给出固定 30 个初值的结果以便解释吸引域。记录失败耗时，不能只计算成功运行的平均时间。
7. 梯度/步长/损失停止条件分别记录。库的容差语义可能不同，不能只把 `gtol` 数字设成一样就声称完全公平。另以公共评价指标判定恢复质量。
8. 各算法仅在独立验证集调参。根据应用目标预先选择“成功率优先、达到同等成功率后比较时间”等规则，并保存调参预算。最终测试集不再逐实例调学习率。
9. 预计算基矩阵计时单独列出；同时报告优化时间与含预计算的端到端时间。预热后计时，不把绘图及文件写入算作求解时间。

## 8. 评价指标及解选择

取同一个整体符号 ε∈{−1,+1}，以光瞳内去 piston 的波前误差最小选择 ε，再报告对齐后的系数误差。对倾斜周期别名另给等价类映射结果，保留原始值，不隐藏偏离应用参数范围的输出。

\[
e_W=\min_{\epsilon=\pm1}\operatorname{std}_{P}
[W(\hat c)-\epsilon W(c_*)],
\qquad e_c=\|\hat c-\epsilon c_*\|_\infty.
\]

为复现历史实验，可另报告 `min(||ĉ−c*||∞,||ĉ+c*||∞)`，注明符号选择口径。主波前指标与逐项系数误差图使用同一符号。

| 维度 | 指标 |
| --- | --- |
| 拟合 | 光强 RMS 残差；有信息区域残差；噪声已知时标准化残差 |
| 恢复 | 去 piston、允许整体符号后的波前 RMS；最大/逐项系数误差；零模泄漏 |
| 可靠性 | 单初值成功率；每个真值多初值成功率；失败类型与退出原因 |
| 成本 | 总时间、达到目标精度的时间、前向/J/梯度调用数、峰值内存 |
| 条件性 | 真值/估计值处 J 的奇异值、数值秩、条件数 |
| 稳定性 | 不同真值/噪声种子下的中位数、分位数与置信区间 |

无噪声可保留 `e_c<1e-6 waves` 的严格恢复阈值，并要求光强残差接近数值精度；同时给出 `e_W<1e-3` 和 `1e-2 waves` 等工程精度曲线。含噪声时主报连续误差分布，成功阈值依据应用要求预先约定，不能沿用无噪声精确恢复阈值。

多初值的最终解只能按观测目标 F 选择，真值只用于事后评价。若噪声导致最低残差解的波前误差更大，仍如实报告。若多个残差接近的解相差很大，输出候选解集合及不确定性，不能借真值挑选部署时无法选择的答案。

置信区间按独立真值进行配对 bootstrap；噪声及初值在同一真值内属于重复观测，不能把所有运行当作独立样本扩大置信度。报告失败样本，避免仅展示最好一次或仅统计成功子集。

建议图表：成功率随总时间的曲线、误差随时间的曲线、幅度×噪声误差热图、初值幅度×算法成功率表、逐模态误差分布、典型失败的预测光强与波前差异、雅可比奇异值谱。

## 9. 代码落地建议

保持现有简洁结构，先完成共享问题与求解器接口，不建立庞大的框架：

```text
lsi/model.py                    # 继续维护唯一前向物理模型
lsi/problem.py                  # 单帧观测、缓存、尺度、残差/J/梯度
lsi/optimizers.py               # GD、Momentum、Adam、GN 与 SciPy 适配
lsi/lm.py                       # 现有 LM，开放配置与诊断记录
benchmark_optimizers.py         # 独立基准入口，配置驱动
tests/test_unmodulated.py       # 无调制不变量、导数与接口正确性
docs/single-frame-optimization-plan.md
```

接口示意：`solve(problem, q0, method, options) -> OptimizationResult`。结果至少含最终系数、loss、退出原因、n_iter、n_forward、n_jac、n_grad、elapsed、逐次 loss/gradient/step 轨迹及具体算法配置。`OptimizationResult` 不在求解器内部保存或访问真值；评价层另行计算恢复指标。

数据输出分为场景配置/观测/真值/初值、每次局部运行结果、每个真值的多初值汇总、图表与报告。保存代码提交号、NumPy/SciPy 版本和线程设置；不要依赖手工复制控制台结果。

测试应覆盖实际风险：无调制导数、共享缩放前后的同一物理解、已知良好非零初值的可恢复样本、零点停滞不误记为恢复成功、预算与计数正确。不能要求所有随机初值都恢复真值；那是实验结论，不是基础单元测试契约。

实施顺序：先共享计算接口和可观测性诊断，再接入七种方法复跑既有案例，随后锁定独立验证/测试集合与预算，最后做噪声及失配扩展。第一轮报告必须同时回答“恢复得多准”“多常恢复成功”“用了多少计算”，再决定是否值得开发组合优化或新初始化方法。

预期但尚待验证：对于目前 12～35 维参数、解析雅可比可用的问题，GN/LM/BFGS 值得优先作为强基线；一阶方法可能更便宜但需要更多更新。现有证据最明确的短板是初值与局部解，因此成功率—计算预算关系应是研究主线。
