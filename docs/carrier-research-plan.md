# 单帧载频反演方法评估：研究计划

日期：2026-10-09。状态：计划稿，尚未执行。

## 1. 要回答的问题

在棋盘光栅二维剪切干涉、**单帧有载频**的采集条件下：

1. 哪一种波前反演方法更好？应该怎样选择？
2. LM 是否优于普通一阶优化算法？
3. 上述结论是否有实验验证？
4. 是否有理论支撑？

### 问题分两层

| 层 | 比较对象 | 决定什么 |
|---|---|---|
| 估计器层 | 傅里叶解调链（取 +f0 瓣 → 解包裹 → 差分 Zernike 最小二乘） vs 直接光强最小二乘（高斯噪声下即 MLE） | 统计精度、偏差、崩溃阈值、对模型失配的鲁棒性 |
| 优化器层 | 解同一个最小二乘目标的求解器：GN、LM、TRF、BFGS、L-BFGS、NLCG、GD、Nesterov、Adam | 能否到达全局极小（可靠性），以及到达所需的真实成本 |

只要几个求解器收敛到同一个极小点，它们的统计性能就完全相同。所以"LM 是否优于一阶算法"是一个数值优化问题，判据是：在给定噪声水平下，以多少真实计算可靠地把优化误差压到统计误差以下。

### 可检验的子问题

| 编号 | 子问题 | 对应原问题 |
|---|---|---|
| Q-A | 直接光强最小二乘和傅里叶解调链相比，偏差、方差、崩溃阈值、失配鲁棒性如何 | 1 |
| Q-B | 各求解器到达全局极小的概率和吸引盆，随像差、剪切量、初值怎么变 | 2 |
| Q-C | 给定 SNR，把优化误差压到统计误差以下需要多少真实计算；GN/LM 与一阶方法的成本交叉点在哪里 | 2 |
| Q-D | 以上结论随 SNR、像差、拟合阶数、模型可信度如何变化，归纳为选择准则 | 1 |
| Q-E | 每条实验结论是否有事先给出、事后验证的理论预测 | 4 |

Q-A 到 Q-D 的实验共同回答原问题 3。

## 2. 已确定的条件与待定项

| 项 | 取值 | 来源 |
|---|---|---|
| 采集模式 | 单帧、已知空间载频；不考虑相移序列和无载频单帧 | 用户确定 |
| 探测器网格 | 128×128（extent 1.10，奈奎斯特 29.1 cyc/unit） | 用户确定 |
| 拟合阶数 | Fringe Z2–Z36（p=35）为主；Z2–Z13（p=12）作对照，用于衔接旧结果 | 用户确定 Z36 |
| 系统参数 | λ=632.8 nm，NA=0.34，光栅周期 30 µm → s=0.0439，f0=11.40 cyc/unit，2f0=22.8 低于奈奎斯特 | `lsi/model.py` 现有载频配置 |
| SNR / 光子数 | 未知，作为扫描因素 | 待定 |
| 像差范围 | 未知，宽范围扫描，结论按像差幅度分档给出 | 待定 |
| 失配幅度 | 未知，宽范围扫描，结论给成"容差曲线" | 待定 |
| 算力 | 小规模 pilot 后决定（见决策点 D1） | 待定 |

在 128×128 网格上调剪切量受混叠约束：2f0 = 1/s 必须低于 29.1，即 s > 0.0344，对应光栅周期 < 38 µm。

本机单线程实测的原语成本（n=128，全像素，5 光束）：

| 拟合项数 | 前向 | 前向 + 完整 J | 比值 |
|---|---|---|---|
| p=12 | 1.3 ms | 4.0 ms | 3.0× |
| p=35 | 1.9 ms | 14.1 ms | 7.4× |

拟合到 Z36 时，一次完整雅可比的代价约是一次前向的 7 倍。按"调用次数"比较 LM 和一阶方法会明显偏向 LM，因此本计划统一按标定后的前向当量和串行墙钟时间计成本。

## 3. 原则

1. **代码只以 `main` 为地基。** `main` 已合并、CI 通过、有回归测试。
2. **现有分支结果一律当作待检验假设。**
   - B 分支 `experiment/single-frame-optimizers` 和 PR #7、#8、#9 只有 Sourcery 机器人审阅。它们的关键数字在阶段 0 中复现后才能引用。
   - PR #10–#14 质量没有保证，不作为依赖，结论不引用。其中的设计思路可以借鉴，但必须重写或逐行审计并配独立测试，包括：固定符号评价与倾斜周期别名诊断（#14）、相机噪声链（#14）、免显式 J 的 Jᵀr（#11）、求解器清单与成本记账（#13）、Hessian 诊断与 λ/ρ 日志（#12）。
3. **先写理论预测，再跑实验。** 预测在主实验前冻结，防止事后解释。
4. **避免同模型自证（inverse crime）。** 现有全部实验都用同一个模型生成数据并反演，会高估直接拟合的优势。下结论的数据必须来自更真实的生成端。
5. **按真实成本比较。** 单线程 BLAS、串行标定原语成本，换算成前向当量。并行运行的耗时不作为证据。
6. **统计规范。** 真值是统计单位；dev 与 test 分离；判定规则预先冻结；只做配对比较。
7. **产物可追溯。** 所有原始结果入库或放在可下载的归档里，并记录源码哈希，不再出现只存在于某台远端机器上的数据。

### 吸取的教训（来自既往实验，作为注意事项）

- 停止阈值的量纲差异曾被误记为"恢复失败"。成功判定要用连续误差，停止状态只作诊断。
- 稀疏像素子采样会改变目标函数景观（512 点与 8192 点得到的吸引盆差 3–4 倍）。像素集要固定并写进协议。
- 一阶方法未调参时的失败（如 Momentum lr=0.01）不能当作方法本身的缺陷。
- 有噪声时真值不是极小点。可靠性要以"参考全局极小"判定，不能以真值判定。

## 5. 阶段 1：理论预测

主实验之前写成备忘，每条预测给出具体数值，然后冻结。

### 5.1 估计器层

- **Fisher 信息与 CRB。** 高斯噪声：FIM = JᵀJ/σ²；Poisson 噪声：FIM = Jᵀ diag(1/I) J。给出 CRB 随 SNR（或光子数）、像差、剪切量、拟合阶数（p=12 与 p=35）的变化。
- **傅里叶链的线性化协方差。** 对整条傅里叶链求关于光强 I 的数值雅可比 L，得到 Cov ≈ σ²LLᵀ，加上无噪声偏差，预先算出傅里叶链的效率和 MSE。
- **失配偏差的一阶公式。** MLE 偏差 ≈ (JᵀJ)⁻¹Jᵀ(I_true − I_model(c*))；傅里叶链偏差 ≈ L(I_true − I_nominal)。由此预测"失配多大时傅里叶链反超 MLE"。
- **低 SNR 阈值。** 预测大误差开始出现的 SNR，包括倾斜周期等价（Z2/Z3 按 1/s 周期平移）和傅里叶链解包裹失败。

### 5.2 优化器层

- **收敛速度。** GD 达到精度 ε 约需 κ·ln(1/ε) 次迭代；Nesterov 约 √κ·ln(1/ε)；BFGS 超线性；GN 的线性收敛率约为 ‖S‖/λ_min(JᵀJ)，S 为残差曲率项，随噪声增大。κ 在整个真值分布上、分别对 p=12 和 p=35 实测。
- **每次迭代成本。** 取自 0.3 的实测值。
- **核心预测：成本交叉点。** 目标精度由 CRB 决定（优化误差 ≤ 0.1σ_CRB），SNR 越低目标越宽松。据此预测一阶方法与 GN 类方法的成本交叉 SNR，以及交叉点随 p 的移动（p 增大时完整 J 的成本上升，κ 也可能增大）。

### 5.3 景观与全局性

- **吸引盆半径。** 非凸性来自光强对级次间相位差的周期性，相位差量级约为 2π·s·∇W。预测吸引盆半径（以波前 RMS 计）大致和 1/s 成正比，并随像差的空间频率升高而缩小。
- **傅里叶链失效。** 当局部条纹频率偏移 s·|∇W| 相对 f0 大到使 +f0 瓣与其他瓣混叠时，傅里叶链失效。预测失效阈值。
- **混叠上限。** 局部条纹频率超过奈奎斯特时两类方法都失效，这给出像差扫描的物理上限。

### 预测清单（E5 逐条核对）

| 编号 | 预测 | 通过判据（草案，G1 冻结） |
|---|---|---|
| P1 | MLE 的协方差达到 CRB（高斯与 Poisson） | 经验协方差对 CRB 的迹比在 1±0.1 内 |
| P2 | 傅里叶链线性化协方差与偏差 | 预测与 Monte Carlo 的迹比在 1±0.2 内，偏差符号与量级一致 |
| P3 | 失配偏差一阶公式 | 小失配区预测偏差与实测偏差相对差 < 20% |
| P4 | 各求解器迭代数随 κ 的标度 | 实测斜率与理论标度一致（对数坐标下） |
| P5 | 一阶与 GN 类的成本交叉 SNR | 实测交叉点落在预测区间内 |
| P6 | 吸引盆半径 ∝ 1/s | 三档剪切量下 r50·s 近似为常数 |
| P7 | 傅里叶链失效阈值 | 实测失效像差落在预测区间内 |

## 6. 阶段 2：实验

### 6.1 公共设置

- **真值池。** 三种谱形：幂律衰减（系数标准差 ∝ (径向阶+1)^−α，α∈{1, 2}）、Z2–Z36 平坦致密、低阶稀疏。RMS 档位 0.01、0.03、0.1、0.3、1、2、3 waves；上限在阶段 1 按混叠上限修正。dev 集约 40 个真值；test 集计划 ≥100 个，规模在 D1 决定。
- **噪声。** 高斯：SNR 20、30、40、50、60 dB（σ = max(I)/10^(SNR/20)）。Poisson：峰值光子数 1e2、1e3、1e4、1e5 e⁻，加 5 e⁻ 读出噪声。
- **初值。** 零初值、傅里叶链输出、独立随机（E2 另行扫描）。初值一律不读真值。
- **参考解。** 每个含噪观测的参考全局极小 ĉ_ref 由多起点高精度求解得到，用梯度范数和 Hessian 正定性核验。

## 7. 统计规范

- **统计单位**是真值；同一真值下的噪声种子和初值是组内重复。
- **配对比较**：按真值聚类的配对 bootstrap 置信区间；不以两个置信区间是否重叠判断显著性。
- **dev / test 分离**：dev 只用于调参和 pilot；协议冻结后 test 一次性运行。
- **预注册判定**："A 优于 B"指配对比值的 95% 置信区间不含 1，且效应量超过预设阈值（草案：MSE 比 ≥ 1.2，成本比 ≥ 2），阈值在 G2 冻结。
- **样本量**：成功概率要估到 ±3% 约需 1000 次运行；协方差迹比的标准误约 5% 需要每条件约 64 个种子（12 项拟合时）。p=35 时的需求在 pilot 中重新估计。

## 9. 最终答案的形态

- **哪种方法好、如何选择**：一张决策图，按 SNR、像差幅度、模型可信度、算力预算给出推荐管线（例如"傅里叶初值 + GN 类精修"或"仅傅里叶链"），并标明每个区域背后的证据。
- **LM 是否优于一阶算法**：成本-SNR 曲线和交叉点，附 p=12 与 p=35 的对比和理论解释。
- **实验验证**：E1–E4 的 test 集结果，全部按预注册判定给出。
- **理论支撑**：P1–P7 的预测-实测对照表。
