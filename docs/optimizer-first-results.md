# 七种优化器：第一轮实现与结果

## 已实现

- `lsi/problem.py`：单帧无调制光强反问题，共用解析雅可比、固定像素及 RMS 参数尺度。
- `lsi/optimizers.py`：GD、Momentum、Adam、BFGS、GN、LM、TRF；真实计算预算、退出原因及评价轨迹。
- `lsi/metrics.py`：整体正负号、倾斜周期等价及系数/波前误差评价，真值不进入求解器。
- `benchmark_optimizers.py`：数据生成、共用初值、噪声、逐次结果、多初值选解和图表。
- `configs/`：冒烟、历史案例、100 真值统计实验和含噪声先导实验配置。
- 实验记录包含源代码快照、依赖锁文件、SHA-256、随机种子、环境与完成状态。

本轮完成 37 项测试，包含原有 11 项回归测试，以及无调制导数、物理等价性、
局部恢复、预算/缓存、初阶更新公式、观测选解和含噪声报告生成验证。

## 完整案例

```bash
uv run python benchmark_optimizers.py \
  --config configs/optimizers-demo.json \
  --output output/optimizers-demo-serial
```

该输出目录已在本轮生成；复跑时换用新目录或省略 `--output`。

使用一个历史真值，128×128 全像素，拟合 Z2…Z13，输入为单帧无相移、无载频光强。
10 个随机方向分别缩放至 0.03/0.1/0.3 waves RMS，再加一个零初值。
七种方法共 217 次求解；下表排除零初值。每次上限为 500 次前向、500 次雅可比计算。
参数使用共同 RMS 坐标，默认梯度容差 1e-10；Momentum/Adam 学习率 0.01，未经验证集调优。

| 方法 | 历史系数恢复标准 | 工程波前恢复标准 | 联合严格标准 | 30 初值总求解秒数 |
| --- | ---: | ---: | ---: | ---: |
| GD | 0/30 | 0/30 | 0/30 | 47.81 |
| Momentum | 0/30 | 0/30 | 0/30 | 46.13 |
| Adam | 0/30 | 1/30 | 0/30 | 47.55 |
| BFGS | 3/30 | 3/30 | 0/30 | 13.13 |
| GN | 3/30 | 3/30 | 3/30 | 7.03 |
| LM | 3/30 | 3/30 | 0/30 | 7.05 |
| TRF | 2/30 | 2/30 | 1/30 | 7.33 |

三种评价口径：

1. 历史系数恢复：允许一个共同正负号后，最大系数误差 <1e-6 waves，与原实验一致。
2. 工程波前恢复：允许共同正负号后，光瞳内去 piston 的波前 RMS 误差 <0.01 waves。
3. 联合严格恢复：符号对齐后的最大系数误差 <1e-6 waves，且光强 RMS 残差 <1e-10。

因此表中 LM/BFGS 的“联合严格恢复 0”不表示它们没恢复系数。例如按观测损失选出的
最佳 LM 系数最大误差约 3.18e-9 waves，光强 RMS 残差约 1.037e-10，恰在额外残差
门槛之外。BFGS 最佳系数误差约 2.11e-9 waves，残差约 1.218e-10。
停止容差与评价阈值是不同概念；后续应预先约定应用精度并查看连续误差曲线，不能只看二值成功标志。

按观测残差选择每种方法的多初值最终解，波前 RMS 误差为：

| GD | Momentum | Adam | BFGS | GN | LM | TRF |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5.21e-2 | 1.90e-1 | 3.14e-3 | 1.48e-9 | 1.83e-12 | 2.41e-9 | 1.59e-14 |

这里没有按真值误差挑选运行。固定初值池的耗时不同，等时间比较应查看
`output/optimizers-demo-serial/budget_curves.csv` 与对应图表，而非直接以总成功率排名。

## 结论范围与下一步

这一案例确认七种算法可在同一观测与初值条件下比较，已有 LM 的系数恢复次数得到复现。
非凸局部解仍是主要困难；GN/LM/BFGS 在某些初值上可达到很高精度。

仅有一个真值，且不同幅值初值共享方向，不能将 30 次运行当作 30 个独立波前样本。
本轮未做学习率/动量等独立验证集调优，也未执行 `optimizers-random.json` 的 21,000 次正式实验。
时间为当前机器实测值，默认单线程、先预热、正式实验串行执行。

建议下一步先用独立验证集选择学习率与合理预算，固定评价阈值，再运行随机波前统计实验。
高斯噪声流程已经实现并通过端到端验证；Poisson 噪声、模型失配、自动调参、峰值内存和
按独立真值 bootstrap 的置信区间尚未实现。
