## B 已实现的模型与解算

以 BUV0725 和 Retrieval0806 为准迁移物理与解算约定。
传播包括点源到物面、环形光瞳 4f 系统、光栅和相机。
每个源独立传播，最后叠加强度，共 64 个源。
没有用四个代表源或五束近似替代原模型。

`Square` 保留参考中的周期方孔阵列。
50% 边长占空比对应 25% 开口面积。
`reference` 与 `retrieval` 分别保留两份参考的轴移差异。
默认未知量为零基模式下标 `7,25,11,15`。

| 模块 | 行为 |
|---|---|
| propagation | 参考三段传播、解析导数、逐源强度叠加。 |
| separable 后端 | 组合相同离散传播算子，支持精确计算选定相机像素。 |
| fourier_original | 保留参考移频、选窗、掩膜、解包裹、平滑和 Lasso。 |
| fourier_calibrated | 独立零像差复边带参考、最小二乘和单项响应标定。 |
| direct | 用传播光强拟合像差、曝光比例和常量背景，保存所有初值结果。 |
| regions / angles | 选窗、掩膜、部件倾斜、已知或忽略几何的对照入口。 |

原版傅里叶系数单位是相位拟合 a.u.。
它们不能直接当作物镜光瞳上的 waves。
标定版本单独命名，不能称作原版算法的原样精度。
其训练使用零像差和对称单项像差，另有混合波前验证。
这需要额外标定数据，比较时应计入方法条件。

## D 已完成的原采样主对比

条件：1200×1200 相机网格、2400×2400 光栅网格、64 源。
使用四模式混合像差，整体缩放至 0.1 waves RMS。
数据无噪声，生成与反演使用同一物理模型。

| 方法 | 波前 RMSE / waves | 最大系数误差 / waves |
|---|---:|---:|
| 标定傅里叶法 | 9.3268e-4 | 5.6060e-4 |
| 直接最小二乘 | 4.2401e-18 | 1.7347e-18 |
| 原版傅里叶法 | 不做 waves 换算 | 保留 a.u. 输出 |

评价使用固定物镜环形光瞳。
主指标沿用参考，去除 piston、双向倾斜和离焦。
同时保留未去除倾斜与离焦的误差及全部系数误差。
不接受整体变号作为正确恢复。

傅里叶标定的独立混合验证误差为 1.3254e-4 waves。
响应矩阵条件数为 1.9729。
直接法本例从零初值出发，使用一个初值。
它的极小误差只说明这一同模型无噪声算例成功。
粗采样大像差实验曾陷入局部极值，失败轨迹已保留。
尚不能据此给出一般恢复率、噪声鲁棒性或仪器精度。

主运行总时间约 154.5 秒，直接拟合记录约 22.4 秒。
这些不是受控硬件计时对比。
完整数据、标定、轨迹及图保存在 `output/diffraction/reference_compare`。
可随代码保留的数字摘要见 `docs/results/verified-summary.json`。

这一结论不能推广为真实扩展光源不受倾斜影响。

## F 运行限制与检查范围

实验命令必须明确指定 `--profile` 或 `--config`。
超过四源小测试规模还必须带 `--allow-large-run`。
判断依据是实际配置的网格和源数，自定义 JSON 也不能绕过。
原采样参数不会自动替换为粗采样。

默认使用一个 worker、每批一个源。
CLI 用同一用户的进程锁阻止并行研究任务。
锁在进程退出时由操作系统释放。
这项限制覆盖实验入口，不是操作系统硬内存配额。

Ctrl-C 或 SIGTERM 会将运行清单标为中断。
已完成的结果行继续保留。
已有运行清单的输出目录拒绝覆盖。
后续重跑应使用新目录；当前没有自动断点续跑功能。

此前完整测试为 24 项通过。
本次只补查运行限制及四源 CLI 小场景，没有重跑原采样实验。
检查包括大任务拒绝、进程互斥、旧结果保护和 SIGTERM 状态保存。
本次检查共 9 项通过，用时 7.90 秒；静态语法与差异检查也通过。
