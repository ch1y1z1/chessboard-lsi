## A 目标与模型基准

研究回答三个问题：

- 在参考的逐段衍射传播模型下，傅里叶法与直接最小二乘法各有多大误差？
- 傅里叶法的频谱选窗和空间有效区，分别怎样影响精度？
- 不同部件、不同方向的倾斜，会怎样影响两种方法？

物理模型以 BUV0725 为准。
传统解算流程以 Retrieval0806 为准。
当前仓库将改为支持这两套参考的统一实验入口。

这里的衍射模型指参考中的标量传播仿真。
它包含光栅透射函数、传播中的衍射与干涉、多源强度叠加。
参考的倾斜处理仍采用小角度相位修正。
计划中的首轮结果将注明这一近似。

```flow LR
参考参数与波前 -> 逐段传播 -> 同一张干涉图
同一张干涉图 -> 傅里叶解算 -> 统一评价
同一张干涉图 -> 直接最小二乘解算 -> 统一评价
```

## C 第二阶段：在同一物理模型下比较两种方法

傅里叶基线保留参考的完整流程：

```flow LR
FFT -> 边带选窗与移频 -> IFFT取相位 -> 解包裹与平滑 -> 差分基拟合
```

先保留参考的 Lasso 参数与经验换算，核对原版结果。
随后建立可追溯的物理单位标定。
标定只使用独立生成的单项像差样本。
标定规则在测试前冻结。
原版与标定版将分别记录，避免混淆改进来源。

用未参与标定的混合像差检验换算误差。
另加无 Lasso 惩罚的线性拟合对照，检查正则化带来的偏差。

直接法以物镜光瞳上的环形 Zernike 系数为未知量。
每次迭代都通过参考传播链预测相机强度。
初期固定源权重和几何参数。

$$
I_{\mathrm{prop}}(\mathbf c,\boldsymbol\theta)
=\sum_q\left|U_q(\mathbf c,\boldsymbol\theta)\right|^2
$$

$$
\min_{\mathbf c,a,b}\;
\sum_{p\in\Omega}w_p\left[
I_{\mathrm{obs},p}-a I_{\mathrm{prop},p}(\mathbf c,\boldsymbol\theta)-b
\right]^2
$$

$\boldsymbol\theta$ 表示角度与几何参数。
$a$ 与 $b$ 表示统一处理的亮度比例和背景。
保存原始强度，避免每次预测都按自身峰值重新归一化。

利用传播算子的线性性质传递场导数。
通过场导数计算光强雅可比，再用阻尼最小二乘更新系数。
先用有限差分验证导数。
预计算传播核，分批处理源点与导数，控制内存。
正式实验保持参考物理采样，计算简化需先通过误差核对。

| 比较条件 | 约定 |
|---|---|
| 输入数据 | 两种方法读取同一张图、同一次噪声实现。 |
| 评价目标 | 主目标为配置中的物镜光瞳像差，单位为 waves。 |
| 平面映射 | 傅里叶输出需映射至同一目标基底；另报其输出平面误差。 |
| 初值 | 直接法使用固定规则与随机种子，报告多初值结果。 |
| 混合方法 | 傅里叶初值再做直接拟合，单列为第三种方法。 |
| 真值使用 | 真值仅供独立标定与仿真评价，不参与测试样本的初始化。 |
| 运行成本 | 记录传播次数、迭代数、时间和峰值内存。 |

先测试参考中的四个非零像差模式及其混合波前。
保留原系数，再增加不同 RMS 的混合波前。
首轮建议 RMS 为 0.05、0.1、0.2、0.4 waves。
先测一次迭代成本，再确定批量实验规模。

验收：给出同一工况下的真值、两种重构、误差图和收敛记录。
局部极值、停止失败和无法恢复的工况也纳入结果。

## D 第三阶段：扫描傅里叶区域选择

将区域分为频谱窗口与空间有效区。
先固定其余步骤，逐项扫描，再研究参数交互。

| 参数 | 首轮建议值或方式 |
|---|---|
| 频谱窗口半宽 | 8、12、16、20、24、28、32 个频谱像素。 |
| 窗口中心 | 围绕参考中心扫描二维偏移；先取 -3 至 +3 像素。 |
| 窗口形状 | 保留参考的平滑矩形；增加圆形、椭圆形和 Gaussian 作对照。 |
| 移频方式 | 先保留参考整数移频；亚像素移频单独验证。 |
| 空间有效区 | 保留参考掩膜，扫描边缘腐蚀宽度与低幅值剔除阈值。 |
| 后处理 | 主扫描固定平滑和正则化参数；另做少量消融检查。 |

窗口半宽 20 是参考基准，不预设为最优值。
窗口尺寸也报告为相对载频间距的比例。
较大窗口可能覆盖零频或邻近边带，这些位置会明确标出。
不同形状按可比面积或有效带宽对照。

先分别扫描半宽、中心和空间有效区。
随后在敏感区间做二维热图，避免一开始穷举所有组合。
观察带宽截断、边带混入、边界误差和解包裹失败。

对同一张图，独立直接拟合只计算一次。
将它作为选窗扫描中的固定参考线。
若使用傅里叶初值，相关变化归入混合方法。

输出：误差随半宽曲线、中心偏移热图、选窗叠加图。
另给出空间掩膜、有效覆盖率和对应误差图。
测试真值下的最优窗只作为分析下界。
实际选窗规则在独立验证样本上确定，再冻结测试。

## E 第四阶段：扫描不同部件的倾斜角度

本计划先把“角度”解释为参考中的部件倾斜。
它与绕光轴旋转、照明入射角或视场角是不同变量。

| 部件 | 参考字段 | 首轮扫描 |
|---|---|---|
| 物面／源阵列平面 | tilted_angle | 绕 x、y 轴分别倾斜。 |
| 光栅相关平面 | tilted_angle_grating | 绕 x、y 轴分别倾斜。 |
| 相机相关平面 | tilted_angle_cam | 绕 x、y 轴分别倾斜。 |

角度建议为 0°、±0.25°、±0.5°、±1°。
每次改变一个部件，其他角度固定为零。
有必要时再加入对角轴和组合倾斜。

参考代码通过输入场的相位修正近似倾斜。
它没有实现严格的旋转平面传播与探测坐标投影。
因此首轮只评价该参考模型中的小角度扰动。
扩大角度范围前，需要独立核对倾斜传播与采样精度。

每个角度设置两组解算条件：

| 条件 | 要回答的问题 |
|---|---|
| 角度已知 | 两种反演都获得相同几何信息，比较算法误差。 |
| 角度被忽略 | 两种反演都沿用名义零角度，观察装调偏差造成的像差串扰。 |

傅里叶法同时比较固定选窗和自动寻峰选窗。
自动寻峰只读取观测频谱，不使用测试真值。
空间掩膜的更新规则也要预先固定。
已知角度组允许按该几何更新标定。
忽略角度组统一沿用零角度标定。
先记录哪些角度与像差相互混淆，再考虑联合估计。

输出：干涉图与频谱随角度的变化、误差随角度曲线。
另报各模式系数偏差、失败次数和有效区域覆盖率。
用窗口半宽与角度的二维图展示两者的交互影响。

## F 统一指标与实验记录

| 指标 | 用途 |
|---|---|
| 波前 RMSE / waves | 主精度指标，在固定物镜环形光瞳内计算。 |
| 残差 PV / waves | 反映局部极端误差，补充 RMSE。 |
| 各项系数误差 | 检查模式串扰和倾斜误判。 |
| 光强残差 | 检查前向数据拟合，但不单独作为波前正确的证明。 |
| 恢复率与失败类型 | 区分优化停止、局部极值、解包裹失败和信息不足。 |
| 时间与内存 | 衡量直接传播拟合的实际成本。 |

主波前指标沿用参考的低阶去除约定。
即统一去除整体相位、双向倾斜和离焦。
同时报告其余可观测项的完整系数误差。
另给出保留离焦的结果，避免隐藏低阶偏差。
两种方法使用相同的去除规则。

波前正负号按参考约定核对。
只有在新传播模型中证实的不可辨识项，才从恢复判据中剔除。

评价光瞳固定，不随选窗变窄而缩小。
有效数据覆盖率单独报告。
先完成无噪声实验，再对代表工况加入噪声重复试验。
记录随机种子和噪声尺度定义。
用分布和失败计数描述结果，保留全部失败样本。

每次运行保存配置、代码版本、输入图、频谱和掩膜。
同时保存标定版本、初值、拟合系数、迭代日志和指标表。
CSV/JSON 保存数值，PNG/SVG 保存图形。
