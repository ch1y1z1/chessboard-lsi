# 三条反演路线的统计效率 vs Cramér–Rao 下界

**结论速览**

1. **LM（光强直接反演，MLE）达到统计极限。** 64 种子 Monte Carlo 中，经验协方差对
   CRB 协方差的广义特征值全部落在 Wishart/Marchenko–Pastur 涨落带内
   （phase_shift：迹均值 0.934，谱 [0.25, 1.92] ⊂ 带 [0.32, 2.06]；carrier：迹均值
   1.007，谱 [0.43, 1.70]），且在 20–60 dB 全 SNR 范围内不变——包括解调链已整体
   崩溃的 20 dB。
2. **解调链存在可观的、SNR 无关的效率损失。** 相移链 η≈0.195（方差为 CRB 的
   ~5.1×，约 −7.1 dB）；载频链 η≈0.60（~1.7×，−2.2 dB）。剪切区受限 FIM 表明
   "只用剪切区像素"只损失 ~5% 信息——损失几乎全部是算法性的。
3. **解调链在 ~30–40 dB 之间开始显著劣化，而 LM 始终贴界。** 相移链 30 dB 时
   12.5% 的运行发生解包裹灾难（η_clean 跌至 0.066），20 dB 时 100% 失败；
   LM 全部 640 次拟合收敛、零灾难。
4. **载频链有 SNR 无关的系统偏差**：Z2 +3.5e-3、Z7 +3.2e-3、Z10 +1.5e-3 waves
   （60 dB 与 20 dB 同值）。在 MSE 口径下倾斜/彗差类系数落后 CRB 2–3 个数量级，
   纯 Var 口径（η≈0.5–0.8）严重低估了其劣化。
5. 最弱可观方向是**倾斜**（Z2/Z3），最强相关对是 **Z4–Z9（离焦–球差，
   ρ≈−0.5，两设计一致）**，另有 Z3–Z8、Z4–Z5（相移设计）。

## 1. 方法

### 1.1 Fisher 信息 / CRB 装配

iid 高斯噪声 `ε ~ N(0, σ²)` 下，非线性回归 `I = m(c) + ε` 的 Fisher 信息矩阵为
`FIM = JᵀJ/σ²`，`J = ∂m/∂c` 在真值 `c*` 处取值。雅可比用 `lsi/lm.py` 的
解析实现 `_frame_and_jacobian`（已有中心差分回归测试锚定）。逐帧计算
`(n_rows × 12)` 的 J 后累加 `JᵀJ`，等价于堆叠 `J_all` 后一次成 Gram 矩阵。

**行集合选择：全部探测器像素**（`samples=None`）。理由：LM 以全图拟合、
解调链也消费全图，全图 FIM 因此对每条路线所见数据精确成立，不存在
"界对子采样、估计器用全图"的口径差。n=128 时全图仅 16384 像素，
16 帧堆叠 262144×12 —— 计算量本来就不大；这同时天然满足"≥8192
黄金比例子采样"的要求（全图是其上确界）。载频调制数组按
`m.reshape(n_orders,-1)[:, rows]` 预切片，与 `fit_wavefront_from_frames`
内部装配完全一致。

CRB：`CRB_i = σ²·(JᵀJ)⁻¹_ii`（waves²）。σ 与 `experiment.add_noise` 同约定：
`σ = max(I_clean)/10^(SNR/20)`，**对整个设计的帧组取单一全局 max**
（见 1.4 备注）。

### 1.2 可观测性谱与相关结构

- `JᵀJ` 特征分解 → `σ_i(J) = √λ_i`；报告谱、条件数及最弱 3 个方向的
  Zernike 展开系数。
- 对照：解调链重构级实际使用的**堆叠差分 Zernike 设计矩阵** ΔZ
  （x/y 两方向剪切区行拼接，未加权），`np.linalg.svd` 谱 + 条件数。
- 相关矩阵 `C = D^{-1/2}(JᵀJ)⁻¹D^{-1/2}`，枚举 |ρ|>0.5 的非对角对。
- **剪切区受限 FIM**（额外的分解实验）：同一 FIM 装配但每帧只保留其
  剪切方向三重交掩膜内的行 —— 分离"掩膜信息损失"与"解调算法损失"。

### 1.3 Monte Carlo

每设计 × SNR∈{60,50,40,30,20}dB × 64 种子。为配对比较采用
**common random numbers**：每个种子抽一张标准正态 z，
`noisy = clean + σ(snr)·z` —— 同格内两条路线、跨 SNR 各格均共享
同一基础噪声实现。

- 路线 A（phase_shift 设计）：`phase_shift_to_wavefront`（8+8 帧 → N 步闭式
  解调 → Poisson 解包裹 → 调制度加权差分 Zernike 最小二乘）。
- 路线 B（carrier 设计）：`fourier_to_wavefront`（单帧 → +f0 瓣解调 →
  阈值+腐蚀掩膜 → 解包裹 → 差分 Zernike）。
- 路线 C（两设计各对应）：`fit_wavefront_from_frames` /
  `fit_wavefront_from_carrier_frame`，零初值，`samples=None`。

统计量（逐系数，误差 Δc = ĉ − c*）：bias、Var(ddof=1)、MSE、
效率 `η = CRB/Var`、`η_mse = CRB/MSE`；稳健口径 σ_robust = 1.4826·MAD，
`|Δc−med| > 3σ_robust` 判离群后重算（`_clean` 后缀）。离群之外另报
**固定物理阈值灾难率**（run 级 max|Δc|>0.05 wave）——当整个分布崩溃时
MAD 同步膨胀、离群率反而失真，两个口径互补。路线异常/NaN 记为 fail。

**Wishart 对照**：逐路线×SNR 计算经验协方差 C_emp 相对 C_crb 的广义
特征值。对恰好达到 CRB 的估计器，12 维、n−1=63 自由度下该谱应落在
Marchenko–Pastur 支撑 `[(1−r)², (1+r)²]`，`r=√(12/63)` → [0.32, 2.06]，
迹均值 ≈ 1。这比逐系数 η（单系数 se(η)≈18%）更能区分真失效与抽样涨落。

最弱方向（J 的特征向量）：

- phase_shift：最弱 ≈ **Z3**（y-tilt，权重 0.97）；其次 Z5、Z2。
- carrier：最弱两个是 **Z2/Z3 倾斜对**（σ=18.06/18.07，对称简并）；再次 Z5。

**解释**：倾斜系数对光强的耦合最弱——W=c·y 使级 (a,b) 的相位只增加常数
`2πc·bs`，即倾斜等价于给各衍射级施加一个小的固定相移，只能通过干涉调制度
的微弱变化观测，灵敏度 ∝ s。这与解调链一致：倾斜的双边差分
`ΔZ = 2s·const` 是剪切区上的常数，信噪比最薄。对照 ΔZ 矩阵条件数
（4.05/4.63）比 cond(J)（9.31/4.83）更小——说明光强可观性瓶颈不在
差分重构这一步的病态，而在干涉图本身的敏感结构。

### 2.3 相关结构

(JᵀJ)⁻¹ 归一化后 |ρ|>0.5 的系数对：

| 设计 | 对 | ρ |
|---|---|---|
| phase_shift | Z3–Z8（y-tilt / y-coma） | −0.566 |
| phase_shift | Z4–Z5（defocus / astig） | −0.524 |
| phase_shift | **Z4–Z9（defocus / spherical）** | **−0.530** |
| carrier | **Z4–Z9** | **−0.503** |

**几何解释**：Z4（2ρ²−1）与 Z9（6ρ⁴−6ρ²+1）都是 m=0 径向模。剪切量小
（s≈0.04–0.07）时双边差分近似 `2s·∂Z/∂u`：∂Z4=4u 是线性坡度，
∂Z9=12u(2ρ²−1) 是以边缘为主的奇对称项——二者光瞳积分内积为正且可观，
于是一个高估的离焦可部分被球差补偿（都在边缘产生同号曲率），CRB 给出
负相关 −0.5。Z3–Z8 同理：彗差含净倾斜分量（Z8=3ρ²y−2y 中有 −2y 的
线性部分），差分信号重叠。径向模在小剪切下差分信号整体偏弱
（∝s·∂Z，ρ⁴ 项的导数幅值集中在边缘窄环），是这类耦合的物理根源。

### 2.6 偏差与 MSE 口径

carrier demod 有 SNR 无关的系统偏差（60 与 20 dB 同值）：
Z2 **+3.5e-3**、Z7 **+3.2e-3**、Z10 +1.5e-3、Z4 +6.7e-4 waves——源于瓣解调的
Butterworth 窗截断与掩膜腐蚀（相位低频失真 + 钉点残差），非噪声。于是
MSE 口径下 `η_mse` 在 Z2/Z7/Z10/Z3/Z9 上为 1e-4–2e-1，落后 CRB
**2–3 个数量级**；单看 Var（η≈0.5–0.8）会严重低估。phase_shift demod 在
≥40dB 偏差可忽略（~1e-6–1e-5），LM 偏差 ~1e-6，均在 MC 精度内与零一致。

## 3. 判定与解释

**(a) LM 是否达到 CRB？** 是。η_clean 中位 1.03（carrier）/ 1.10
（phase_shift），Wishart omnibus 谱落在 MP 带内、迹均值 ≈0.93–1.01，
逐种子等于线性 MLE 预测，收紧容差不改变方差。在 iid 高斯光强噪声下
LM 是严格的 MLE，这里在全部 20–60dB 范围内经验地达到渐近界。

**(b) 解调链损失多少？** 相移链 η≈0.195 → **方差 ~5.1×CRB（−7.1dB）**；
载频链 η≈0.60 → **~1.7×CRB（−2.2dB）**，外加 tilt 类系数的固定偏差
（MSE 口径落后 2–3 个数量级）。剪切区受限 FIM 实验表明"只解调剪切区
像素"只解释 ~5%（A）/~2%（B）的损失——**损失几乎全部是算法性的**：
N 步相移解调只取频率-1 分量，丢掉二次谐波拍频项 `2A1²cos(4πhxd+2δ)`
（同一 ΔW 的两倍条纹频率信息）与全部和频/背景项；解包裹后的相位噪声
空间相关且异方差，调制度加权 LSQ 不等于白化；载频链额外引入滤波窗的
噪声相关性与截断偏差。

**(c) 劣化阈值：** 相移解调链在 **40→30dB 之间**开始显著劣化
（η 0.195→0.066，灾难率 0→12.5%），20dB 完全崩溃（100%）；LM 全程
贴界、零失败。载频解调链因低通滤波的空间平滑对噪声更鲁棒，到 20dB
仍不崩，但它**在任何 SNR 都没接近过界**，且有偏差下限 ~3.5e-3 waves——
即"不崩溃"与"接近极限"是两回事。

## 4. 局限

- **样本量**：64 种子 → 单系数 η 的 se≈18%（√(2/63)），omnibus 迹
  se≈5%；η∈[0.65,1.76] 的逐系数散布即此涨落，不宜过度解读单格数值。
  需要更紧的置信带可增至 256 种子（脚本 `--seeds` 可调）。
- **单一真值**：c* 为中等等级像差（PV≈1.2 wave，RMS 0.24）。更大波前会使
  `cos Γ` 在剪切区变号，两条解调链按各自方式劣化（本实现未覆盖该工况）；
  LM 按结构不受此限。
- **噪声模型**：iid 高斯、加性于光强；未含 Poisson 散粒、量化、
  空间相关噪声。CRB 随噪声模型改变（散粒噪声下 FIM 非线性于 I）。
- **界是局部量**：FIM 在 c* 处取值，未纳入 nuisance 参数（对准误差、
  级次振幅标定误差、像素响应不均匀）——实际系统余量应更差。
- **σ 口径**：全设计单一全局 max(I)；x/y 扫描峰值差 ~2×（1.72/0.89），
  逐方向归一化会改变相移设计 y 扫帧 ~5.7dB 的有效 SNR。
- **载频低通窗**：η≈0.60 与偏差数值依赖当前 Butterworth 窗半径/腐蚀量
  的实现选择；换窗参数会改变数值但不改变 LM 的界与效率结论。
- 路线 A/B 的"demod"按论文链路原样统计（含其掩膜腐蚀、权重选择），
  未做"解调链的最优变体"这种反事实实验。
