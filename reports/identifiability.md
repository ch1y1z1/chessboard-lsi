# LM 反演的可辨识性谱系与原点驻点定性

对 `lsi/lm.py` 的 Levenberg–Marquardt 直接光强反演做系统化的可辨识性分析：
**(1)** 帧设计（调制方式/帧数）→ 解的唯一性与盆地捕获率；**(2)** 无调制单帧
原点驻点 `J(0)=0` 的 Hessian 定性；**(3)** 可观测性 `cond(JᵀJ)`/`σ_min(J)`
随剪切量与拟合阶数的粗扫。

真值与约定全部沿用 `experiment.py` 第 5 节：`TRUTH_IDX=[4,5,6,7,8]`、
`TRUTH_C=[0.31,−0.12,0.07,0.42,0.05]`（waves），拟合 `INDICES=Z2..Z13`
（12 项，Z1 平移不可观），网格 `n=128, extent=1.10`。相移帧设计用默认
配置（λ=632.8 nm, NA=0.34, p=18 μm → s=0.0731）；载频设计用 p=30 μm 配置
（s=0.0439, f0=1/2s≈11.4 cyc/unit）。LM 每帧采样 4096 像素（与
`fit_wavefront_from_frames` 相同的黄金比例低差异序列），初值 = 10 个固定
随机方向（种子 42）× 波前 RMS∈{0.03,0.1,0.3} 共 30 个/设计，另加 1 个
零初值作参照（不计入占比）。分类阈值：+W 为 `max|c−c*|<1e−6`，−W 为
`max|c+c*|<1e−6`，其余收敛点为"其他极小"（终值按系数 max 距离 <1e−4
贪心聚类），`converged=False` 为"不收敛"。

复现入口：

```bash
uv run python analysis/identifiability.py   # ~80 s, 279 次 LM 拟合 + t 扫描
uv run python analysis/origin_hessian.py    # ~4 min, 解析 Hessian + FD 校验
uv run python analysis/observability.py     # ~2 min, J 的 SVD 扫描
```

## 1. 可辨识性谱系：帧设计 → 唯一性

### 1.1 对称性度量与盆地分类

`sym = max|I(c*)−I(−c*)|`（逐帧、采样像素上取最大）：**0 ⇒ ±W 简并对该帧组
精确成立**；非零 ⇒ ± 对称被破缺（简并至多剩残余的局部极小，不再是精确解）。

| 帧设计 | 帧数 | sym max\|ΔI\| | +W | −W | 其他极小 | 不收敛 | 伪极小簇 |
|---|---|---|---|---|---|---|---|
| raw1（无调制） | 1 | **0（精确）** | 3/30 (10%) | 0/30 | 27/30 (90%) | 0 | 8 簇 = **4 个严格 ± 对** |
| dx, t=1/8 | 1 | 1.008 | 26/30 (87%) | 0 | 2 (7%) | 2 (7%) | 2 |
| dx, t=1/4 | 1 | 1.454 | **30/30 (100%)** | 0 | 0 | 0 | 0 |
| dy, t=1/8 | 1 | 0.565 | 24/30 (80%) | 0 | 6 (20%) | 0 | 2 |
| dx+dy, t=1/8 | 2 | 1.008 | 29/30 (97%) | 0 | 1 (3%) | 0 | 1 |
| dx, t=i/4 | 4 | 1.454 | 17/30 (57%) | 0 | 13 (43%) | 0 | 2 |
| dx, t=i/8 | 8 | 1.454 | 17/30 (57%) | 0 | 13 (43%) | 0 | 2 |
| dx+dy, t=i/8 | 16 | 1.454 | **30/30 (100%)** | 0 | 0 | 0 | 0 |
| 载频 p=30 μm | 1 | 1.295 | **30/30 (100%)** | 0 | 0 | 0 | 0 |

（占比按 30 个随机初值；零初值单列见下。完整逐次记录见
`output/identifiability_runs.csv`，伪极小系数向量见
`identifiability_minima.csv`，图 `identifiability.png`。）

### 1.2 结构性事实（数值验证）

级次振幅 `A_ab` 全为实数，故恒等式 **`I(c, δ) ≡ I(−c, −δ)` 精确成立**
（mod 2π 意义上 −δ≡δ 时同帧简并恢复）。单帧 t 扫描
（`analysis/identifiability.py: symmetry_scan` → `symmetry_scan.csv`）：

| t | dx sym | dy sym |
|---|---|---|
| 0 | 0 | 0 |
| 1/8 | 1.008 | 0.565 |
| 1/4 | 1.454 | 0.579 |
| 3/8 | 1.079 | 0.281 |
| **1/2** | **1.8e−15** | **1.9e−16** |
| 5/8 | 1.079 | 0.281 |
| 3/4 | 1.454 | 0.579 |
| 1 | 7.8e−16 | 8.9e−16 |

即 `t=0` 与 `t=1/2`（δ=±π≡∓π）、`t=1`（δ=±2π≡0，等价无调制）三个自逆
/平凡点上 ± 简并恢复，其余 t 破缺——单帧相移的破缺对相移量敏感，
半周期步进无效。也就是说，**破缺 ± 简并只需要任一帧的调制不满足
δ≡−δ (mod 2π)**；本网格中除 raw1 外全部满足，sym>0。

### 1.3 盆地结构观察

- **raw1 的失败不是收敛到 −W，而是落入伪极小**：27/30 收敛到 8 个非零残差
  极小点（rms 残差 0.008–0.016），它们严格组成 4 个 ± 对（聚类间距
  max|Δ|≤1e−6）——整个极小点图景仍是 ± 对称的，与 `F(c)=F(−c)` 一致。
  无一例收敛到 −W 纯属初值集合的偶然（30 个方向不带 ± 对称覆盖）。
- **单帧相移足以唯一钉死解**：`dx(t=1/4)` 在全部 30 个初值下收敛 +W
  （rms~1e−16 精确解），迭代中位数 8。`dx(1/8)`（87%）与 `dy(1/8)`（80%）
  表明破缺强度/方向影响盆地捕获率。
- **单纯增加同方向相移帧不保证更好**：`dx4`/`dx8` 只有 57%，且两者收敛到
  几乎相同的 2 个伪极小簇（残差 ~6–7e−2）——只有 x 方向相移时，y 对衍射级
  始终不带调制，伪盆地不被帧数消除。这与 Part 2 的梯度分析一致：多帧只
  放大已有信息。
- **两方向相移（哪怕各 1 帧）或载频最稳健**：`dx+dy`（97%）、`dx8+dy8`
  （100%）、`carrier`（100%，且迭代最少 ~6 次）。
- **零初值**：raw1 在 1 次迭代内停在原点（`J(0)=0`→`‖g‖=0`→GTOL 命中，
  这就是 experiment.py 第 5 节零初值失败的机制）；其余所有设计从零初值
  直接收敛 +W——原点已非驻点。
- 失败与初值 RMS 的关系：dx_1/8 的失败集中在 RMS=0.3 组（大初值更易越过
  进入伪盆地）；dy_1/8、dx4/dx8 的失败则是固定几个方向在所有 RMS 下重复
  ——由初值**方向**决定，不是幅度。

### 1.4 结论：最少需要什么样的帧

- **形式上唯一**：任何使 `δ_ab ≢ −δ_ab (mod 2π)` 的单帧即破缺 ± 简并
  （对称性度量 >0）；避开 `t=1/2` 这类自逆相移。
- **实际上可靠**：单帧 `dx(t=1/4)`、单帧载频（p=30 μm）或两方向相移组合
  在本真值/基底/采样下达到 100% 盆地捕获；单纯 x 方向多帧相移不单调改善。
- 推荐最小配方：**单帧载频**（迭代最少、无伪极小）或**两帧 dx+dy(t=1/8)**；
  若只能单帧相移，用 `t≈1/4`。

## 2. 原点驻点的定性

### 2.1 解析公式与校验

每帧每像素（`analysis/origin_hessian.py: frame_derivatives`）：

```
∂E/∂c_j        = Σ_m A_m e^{iφ_m} (i2π) Z_j^{(m)}
∂²E/∂c_j∂c_k   = Σ_m A_m e^{iφ_m} (i2π)² Z_j^{(m)} Z_k^{(m)}
∂²I/∂c_j∂c_k   = 2 Re[(∂E/∂c_k)* ∂E/∂c_j + E* ∂²E/∂c_j∂c_k]
∇²F = 2 Σ_frames (JᵀJ + Σ_i f_i ∇²I_i),   ∇F = 2 Σ Jᵀ f
```

校验（非零 c，无调制与 δx(1/8) 两种情形）：解析 `∂²I` 对解析 J 的中心差分、
`∇F`/`∇²F` 对 F/∇F 的中心差分全部通过（`verify_derivatives`，log 首行）。

### 2.2 无调制单帧：原点是鞍点

`J(0)=0`（dE 纯虚、E 实）⇒ `∇²F(0)=2Σ_i f_i(0)·∇²I_i(0)` 完全由数据决定。
对 nominal 真值（F(0)=18.8）：

```
eig ∇²F(0) = {-916, -157, -141, -89, -32, -30, -1.4, -0.02,
              +5.8, +16.2, +29.1, +88.3}
             8 负 / 4 正 → 鞍点（tr(H) = -1228 < 0）
```

- **鞍点对一切非零真值成立**：defocus/astig/coma/spherical/大振幅/小振幅
  逐一出鞍（7–8 个负特征值）；`flat W=0` 是唯一例外：`f(0)=0` 且 `J(0)=0`
  ⇒ `∇²F(0)≡0`（精确退化；F(0)=0 即全局极小，原点是"平地井底"）。
- **谱幅度 ∝ |c\*|²**（小振幅）：λ_min 从 nominal 的 −916 到 0.1× 真值的
  −9.65（≈0.01 倍；因为 J(0)=0 使 `f(0)=I(0)−I(c*)` 本身是 c* 的二阶量），
  大振幅端次线性饱和（2× 真值 → −2469，约 2.7 倍）。
- **不稳定方向含显著真值分量**：nominal 最负特征向量
  u_min ≈ 0.65·Z9 + 0.49·Z12 + 0.38·Z7 + 0.35·Z4——真值支撑模式
  （Z4..Z8）合计占 |u_min|² 的 ~30%（Z7/Z4 两个分量直接是下山方向），
  但最大两个分量 Z9/Z12 并不在真值支撑上。
- **逃逸实证**：沿最小特征方向 ±10⁻⁴·u_min 起 LM，**所有非零真值**下都
  离开原点不再回来；flat W=0 例外——其原点本来就是极小点（H≡0 的平地
  井底），±ε 微扰收敛回 |c|~1e−5（r~2e−11）。一维剖面扫描显示鞍点真值
  在最低 6 个特征方向 ± 两侧全部自 t=0 起即下降，随机方向亦绝大多数如此
  （nominal 12/12，coma 10/12，其余 12/12）——逃逸对任意小随机扰动是
  普适的。单模真值（Z4/Z9）在 ε=10⁻³ 时按扰动符号分流到 ±W 精确解；
  多模真值落入 §1 的 ± 成对伪极小（残差 ~1e−2）。这与 experiment.py
  第 5 节完全自洽：0.03 RMS 组全部逃逸（1/10 到 +W，9/10 到伪极小，
  0 停滞），唯一卡住的是零初值本身。
- **尺度参照**：唯一的极小情形（flat W=0 + raw1，原点即全局极小）的
  剖面扫描显示盆地宽阔：12 个随机方向中仅 1 个在 t≤1.0 内出现首个局部
  极大（t≈0.96），其余 11 个单调上升至扫描端点——多数方向上该盆地
  半径 ≥1 波（中位数统计样本量为 1，仅作下限参照）。

### 2.3 调制/载频帧：原点非驻点

`J(0)≠0` ⇒ `∇F(0)=2Jᵀf ≠0`，且下降方向指向真解：`cos(−∇F(0), ĉ*)` 对
nominal 为 0.76（dx_1/8）、0.65（dy_1/8）、0.82（dx+dy）、0.86（dx8+dy8）、
0.88（carrier）；对 −c\* 真值同样为正（0.70–0.91，相对该数据的真分支）。
flat W=0 + 调制帧时 `F(0)=0, ∇F=0, ∇²F=2JᵀJ` 正定（λ_min>0，0.18–139 随
帧数增长）——原点就是真解的严格局部极小，与 Part 1 中零初值收敛一致。

本节覆盖 9 种帧设计中的 6 种（raw1、dx_1/8、dy_1/8、dx+dy_1/8、dx8+dy8、
carrier_p30；未含 dx_1/4、dx4、dx8 三个同家族变体）——定性结论
（鞍点/非驻点/退化）在该覆盖面上已一致。

（逐格数值：`output/origin_hessian_summary.csv`；全谱
`origin_hessian_spectrum.csv`；盆地扫描 `origin_hessian_basin.csv`；
图 `origin_hessian.png`。）

## 3. 可观测性曲线（粗扫）

J 在 c\* 处取值、堆叠 8+8 相移帧（16×4096 行）或单帧载频（4096 行；
不同设计行数不同，σ 的绝对值不可直接比较，cond 可比）。

### 3a 剪切量扫描（Z2..Z13）

**混叠警示**：n=128/extent=1.10 网格的轴向奈奎斯特 ≈29.1 cyc/unit，而光强
含 ±1 级间拍频 `2f0 = 1/s`——`s < 0.0344` 时载频帧欠采样混叠。12 个
(period, NA) 格子中 **4 个的载频列处于混叠区**（p=30/NA=0.6 与 p=60 全部
三个；`observability_shear.csv` 的 `aliased` 列与图中 `x` 标记）。混叠格
上载频 cond(JᵀJ) 停在 ~29 的可疑平台，很可能主要是点采样 moiré 而非物理
可解析条纹（真实探测器像素会积分模糊掉它们）。**cond 对所定义的离散
最小二乘问题仍然精确，但不外推到欠采样条纹的物理情形。**

| s | cond(JᵀJ) ps_8+8 | cond(JᵀJ) carrier |
|---|---|---|
| 0.199 (p=9 μm, NA=0.25) | 15 | 7 |
| 0.073 (p=18, NA=0.34，标称) | 85 | 19 |
| 0.044 (p=30, NA=0.34) | 146 | 24 |
| 0.022 (p=60, NA=0.34) | 234 | 29 *(混叠)* |
| 0.012 (p=60, NA=0.6) | 290 | 29 *(混叠)* |

- σ_min(J) 单调随 s 减小（52→1.4，约 ∝ s^1.3），扫描范围内**无悬崖**；
  不可观性在 s→0 方向平滑恶化，真正的爆炸发生在 s≪0.01 之外。
- **无混叠格子上载频帧的 cond 比 8+8 相移低 ~2–6 倍**（8 个无混叠格
  实际区间 2.1–6.3；全 12 格含混叠时为 2.1–9.9，高端即被混叠平台污染）——
  单帧载频给各级次提供多样化空间相位调制，每像素信息量更高。Part 1 的
  载频设计（p=30, NA=0.34 → 2f0=22.8 < 29.1）不在混叠区。
- 固定 NA 减小 s 与增大 NA 减小 s 的条件数增长趋势一致（由 s 主导）。

## 5. 局限

- 盆地占比是**经验量**：依赖本真值、Z2..Z13 基底、4096 像素采样与
  30 个固定初值方向（每格 ±~10% 统计粒度）；± 简并、鞍点定性是结构性的。
- 对称性度量只覆盖 ± 配对简并；不保证排除其他精确解（第 2 节的伪极小
  均为非零残差局部极小；对低复杂度真值未系统穷举精确解集）。
- `samples=4096` 采样与 experiment.py 第 5 节全像素略有差别：全像素
  重跑边界格子会把 1–2/30 个运行翻转到分类另一侧（如 dx4 dir4 由
  other→+W），即占比有 ~±1/30 的采样敏感性；± 简并（逐点代数恒等式）、
  鞍点定性与设计排序等结论不变。
- §3a 载频列的条件数对离散最小二乘问题是精确的，但混叠格子
  （`aliased` 列）不代表欠采样条纹的物理情形。
- 全部无噪声；cond(JᵀJ) 只刻画灵敏度不刻画 SNR 性能。
- Part 2 的 ∇²F 在 `samples=4096` 采样网格上求和；换像素支撑数值会
  变，定性（鞍点/退化/非驻点）已核对与真值结构无关。
